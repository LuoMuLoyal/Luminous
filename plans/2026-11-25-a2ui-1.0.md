# A2UI 1.0：genui → a2ui_flutter，交互（动作 / 表单 / 函数调用）交给 agent

Created: 2026-11-25。取代 `plans/2026-10-31-a2ui-generative.md` 的 §1 版本口径与
§6「三条安全边界」——那三条本次**全部撤销**。

## 0. 已定结论

| 项 | 结论 |
| --- | --- |
| 包 | `a2ui_flutter ^0.5.0` + `a2ui_core ^0.9.0`；删除 `genui`。两者支持协议 v1.0 |
| 协议 | v1.0，消息 `version: "1.0"` |
| 兼容 | **零兼容**：v0.9 消息与旧缓存都没有读取路径 |
| 能力 | 1.0 新能力一次做完：双向函数调用、`createSurface` 内联、accessibility、extensions |
| catalog | **全量开放**：basic catalog 全部组件（含 Button / TextField / CheckBox / ChoicePicker / Slider / DateTimeInput / Tabs / Modal / Video / AudioPlayer）+ 领域 item |
| 安全边界 | **删除**：不再禁数值、不再禁写动作、不再要求领域 item 只收引用键。按普通 agent 软件对待 |
| 词汇表归属 | 客户端 advertise（把 catalog 文档随请求上行），服务端不再维护第二份 |
| 会话 | 服务端**无状态**：每次交互上行携带当前文档 + dataModel |

## 1. v0.9 → v1.0 差异（本仓用到的部分）

| 维度 | v0.9（现状） | v1.0（目标） |
| --- | --- | --- |
| 信封 | `version: "v0.9"` | `version: "1.0"` |
| 下行消息 | create / updateComponents / updateDataModel / deleteSurface | 上述四种 + `callRendererFunction` / `agentFunctionResponse` |
| 上行消息 | 无（本仓未接） | `action` / `callAgentFunction` / `rendererFunctionResponse` / `error` |
| 通用键 | `catalogId` / `accessibility` | `@catalogId` / `@accessibility` / `@checks` / `@metadata` |
| 绑定 | `{"path": "/x"}` | `{"@path": "/x"}` / `{"@call": "..."}` |
| 建面 | 只能先建空面 | `createSurface` 可带 `components` + `dataModel`；`theme` **非法** |
| catalog | 一表面一 catalog | 每组件可带 `@catalogId` 混用；函数定义改为对象 map |
| 数据 | 单向 | `sendDataModel` 让渲染端把 dataModel 随上行动作回传 |

## 2. 目标数据流

```text
生成：
  client  POST /layouts/:surface/generate { prompt, range?, capabilities }
  server  → SSE  chunk(A2UI 消息) / result{ messages, dataModel? } / error / done
  client  processor.processMessages(...)      → A2uiSurface 渲染

交互：
  user    Button / TextField / Slider …（组件自带 action，数据写进 dataModel）
  client  processor outbound → POST /layouts/:surface/turn
          { messages: <renderer→agent>, document: <当前消息序列>, dataModel, capabilities }
  server  → SSE  同上四帧（agent 针对这次交互续写的消息）
  client  processMessages 叠加到同一 surface
```

一个 surface 一个 `MessageProcessor`，跨生成与交互复用——surface 一旦删除再交互就是
无效消息，由 `a2ui_core` 报 `INTEGRITY_ERROR`，不需要本仓补判定。

## 3. 客户端改动

### 3.1 依赖（`pubspec.yaml`）

```yaml
a2ui_flutter: ^0.5.0
a2ui_core: ^0.9.0
json_schema_builder: ^0.1.7   # ComponentImplementation.schema 仍用它
# 删除：genui ^0.10.4
```

`a2ui_flutter` 自带 `video_player`（Video / AudioPlayer 的渲染依赖）——这是全量
catalog 的直接代价，记进包体核对项。macOS 需要 `com.apple.security.network.client`
（网络图片/视频），与现有联网 entitlement 是否重复待核对。

**已核对**：`flutter pub get` 已通过（a2ui_flutter 0.5.0 / a2ui_core 0.9.0 /
video_player 2.14.1），连带移除了 `genui`、`genai_primitives`、`audioplayers*` 与
**`video_player_win`**。也就是说 Windows 桌面端 `video_player` 没有平台实现，
`Video` / `AudioPlayer` 在窗口里渲染不出来。两个选择：接受（网页/移动端可用），
或把 `video_player_win` 显式加回依赖。**先按接受处理**，桌面端不演示媒体组件。

### 3.2 渲染接缝：`lib/core/composition/genui/` → `lib/core/composition/a2ui/`

包名已经不存在，目录跟着改；仍是 `lib/` 里唯一允许 import `a2ui_*` 的地方。
保持 3 个文件，不加新层：

| 文件 | 改动 |
| --- | --- |
| `transport.dart` | `SurfaceController` + `A2uiTransportAdapter` → `MessageProcessor<ComponentImplementation>`。暴露：`process(json)`、`outbound` 流（`RendererToAgentMessage`）、`surface(id)`、`dispose()`。不再有 `feedChunk`（agent 端已解析，无文本流） |
| `surface.dart` | `genui.Surface` → `A2uiSurface`；保留 `_GenerativeMaterialScope`（basic catalog 是 Material 组件，Forui 主题映射不变），补输入控件的 `inputDecorationTheme` / `checkboxTheme` 映射；`Text` 的 markdown 用 `A2uiMarkdown` + `MarkdownBody`（依赖已在） |
| `catalog.dart` | 白名单构造 → `basicCatalog()` + 本仓 catalog；`GenerativeCatalog` 只剩「注册哪些 catalog、catalogId 是多少、给 agent 的文档是什么」 |

新增职责：`catalogDocument()`——返回可上行的 catalog 文档（`CatalogImplementation.toJson()`
去 `examples` 以压提示词体积）。这是服务端提示词的唯一来源。

两个构造细节（读 0.5.0 源码确认）：

- `basicCatalog({String locale = 'en-US', OpenUrlCallback? openUrl})`——`locale` 决定
  数字/日期/`formatString` 的格式，必须传当前 app 语言（`zh-CN` / `en-US`）而不是吃默认值；
  `openUrl` 不传时 agent 的 `openUrl` 调用直接失败。是否给回调 = 是否允许 agent 打开外链，
  本期**不给**。
- `CatalogImplementation` 只是 `Catalog<ComponentImplementation, FunctionImplementation>`
  的 typedef；`ComponentImplementation` 的 builder 签名是
  `(BuildContext, ComponentNode, ComponentProps, ChildWidgetBuilder)`。

### 3.3 组合根：`lib/app/composition/generative/`

领域 item 从 `CatalogItem`（genui）改为 `ComponentImplementation`：

| 文件 | 改动 |
| --- | --- |
| `catalog.dart` | 装配 `[basicCatalog(), luminousCatalog]`，`catalogId` 用常量 `https://luminous.app/a2ui/catalog/v1.json` |
| `items/metric_card.dart`、`trend_chart.dart`、`finding.dart` | schema 保留引用键（`kind` / `range` / `findingId` 的 enum）；builder 签名改 `(context, node, props, buildChild)`，取值走 `props.string` / `props.number` |
| `generation_repository.dart` | 不变 |

领域 item 继续只收引用键，但理由从「安全边界」降级为「领域数据本来就在 Riverpod 里，
让 agent 抄一遍没有意义」。agent 想直接写数值时用 basic catalog 的 `Text`，现在允许。

### 3.4 `lib/features/generative/`

| 层 | 改动 |
| --- | --- |
| `domain/services/catalog_policy.dart` | **删除**。准入规则随安全边界一起撤销；结构合法性由 `a2ui_core` 校验并通过 `onError` 上报 |
| `domain/services/item_catalog.dart` | 只剩 enum 取值（`generativeMetricKinds` / `generativeFindingIds`），供 schema 构造 |
| `domain/entities/generation.dart` | `GenerativeSurfaceDocument` 增加 `dataModel`（nullable）；`isEmpty` 口径不变 |
| `domain/repositories/generation.dart` | 增加 `sendTurn` 的事件类型（复用 `GenerationStreamEvent`） |
| `application/orchestrators/generation_session.dart` | `commit` 不再校验；新增 `applyTurn(event)`：增量消息应用 + `result` 覆盖文档；`fail` 语义不变 |
| `data/datasources/generation_remote.dart` | 新增 `turn({surface, messages, document, dataModel, capabilities})`；`stream` 请求体加 `capabilities`；`chunk` → 仍交给 processor |
| `data/datasources/generation_cache.dart` | 键改 `a2ui.<surface>.document`（消息序列 + dataModel）。无迁移路径 |
| `data/repositories/cached_generation.dart` | 对齐上面两个口子 |
| `presentation/providers/surface_state.dart` | 一个 surface 一个 processor；`GenUiEnabled` 开关名改 `genAiSurfacesEnabled`（沿用现有 KV 键） |
| `presentation/providers/generation.dart` | 订阅 processor outbound → `sendTurn` → 应用返回帧；surface 删除时清 processor |
| `presentation/widgets/generative_surface.dart` | `GenerativeSurfaceRenderer` 入参改为 `SurfaceModel`；三态不变 |

`lib/shared/domain/generative/data_scope.dart` **删除**（它只为「客户端告诉服务端可引用
哪些维度」而生，词汇表改由 catalog 文档承载）。`message_error.dart` 保留，语义改为
「渲染端拒绝了这条消息」。

### 3.5 布局与交互约束

- `A2uiSurface` 需要 Material 祖先：现有 `_GenerativeMaterialScope` 已满足。
- agent 的树可能给 `TextField` 无界高度（外层是滚动的 `Column`）——渲染入口统一套
  `LimitedBox`/固定宽度，否则输入框布局直接报错。
- `props.action(key)` 是用户激活语义，只能在手势回调里同步调用；本仓不在别处替它调。

## 4. 服务端改动（Lucent，任务清单在 `Lucent/plans/2026-11-25-a2ui-1.0.md`）

契约变化决定客户端怎么接，先把形状钉死：

```text
POST /layouts/:surface/generate
  body: { prompt: string, range?: "7d"|"30d", capabilities: object }
  → SSE chunk / result / error / done

POST /layouts/:surface/turn
  body: { messages: object[], document: { messages: object[], dataModel?: object },
          capabilities: object }
  → SSE chunk / result / error / done
```

- `capabilities` = 3.2 的 catalog 文档（客户端唯一权威），服务端只做「是不是对象、
  有没有 components 数组、体量上限」的形状检查。
- 服务端 `surface-policy.ts` 的三条内容规则删除，只留信封结构校验（有 `version`、
  六个消息键之一、有 `root`）。
- 提示词由 catalog 文档生成，不再手抄词汇表。

## 5. 缓存

键 `a2ui.<surface>.document`（消息序列 + dataModel）。新键之外没有读取路径：不清理、
不迁移、不判断旧内容——旧数据对这套代码不存在。

编排页的 `genui.<surface>.spec`（用户改的标题）与生成结果无关，键保持不动。

## 6. 验收

1. agent 可下发 basic catalog 任意组件——含 Button / TextField / CheckBox / Slider /
   ChoicePicker / DateTimeInput / Tabs / Modal，渲染无异常。
2. 点 Button 产生 `action` 上行，服务端返回的新消息叠加到同一 surface。
3. TextField / Slider 的写入进 dataModel；下一次 action 的 metadata 带上 dataModel。
4. `Text` 内的 markdown 正常渲染（标题 / 列表 / 粗体）。
5. 冷启动重放包含交互态（dataModel）的文档，不重烧 LLM。
6. `callRendererFunction` 由 client 端的函数注册处理（先接 `openUrl` 需要时才加，
   不预埋）；`callAgentFunction` 走 `turn`，未知函数名返回合法
   `agentFunctionResponse` 错误而不是断流。
7. 测试与门禁全绿：`flutter analyze`、`flutter test`、
   `luminous_lints --clean-layers`、`dart run scripts/docs/verify.dart --warning-only`。

## 8. 风险

| 风险 | 应对 |
| --- | --- |
| 0.x 包 API 再变（`MessageProcessor` / `ComponentImplementation` / `props`） | 只出现在 `core/composition/a2ui/`，升级改一处 |
| 交互竞态：连点、surface 被删、turn 乱序 | 一个 surface 串行化 turn；surface 删除即丢弃未完成 turn |
| catalog 文档进提示词后体积过大 | 上行前剥 `examples`；仍超限则先在客户端裁 description |
| `video_player` 引入原生依赖 | P1 结束时跑一次四端构建核对，macOS entitlement 单独验 |
| 双轨状态：dataModel 与 Riverpod | dataModel 是交互态唯一来源；业务数据只经领域 item builder 只读注入 |

## 9. 本次不做

- v0.9 兼容层、旧缓存迁移或清理。
- 服务端会话/历史存储（每次带上文档，无状态）。
- 真 `callAgentFunction` 工具集（先把通道与错误应答跑通）。
- 重新引入组件白名单。
