# elk_icon_picker 集成计划 — Bridge Map 方案

**Goal:** 引入 `elk_icon_picker` 作为用户图标选择器 UI，通过 bridge map 将其返回的图标名转换为 Forui `FLucideIcons` 的 `IconData`，实现记录页快捷入口和用药页药品图标的用户自定义。

**方案:** Bridge Map（方案一）— `elk_icon_picker` 仅充当选择器 UI，选完后通过生成的映射表将 kebab-case 图标名转为 `FLucideIcons` 的 `IconData`，实体模型和渲染层零改动。

**Tech Stack:** Flutter, Forui, elk_icon_picker 0.1.3, SharedPreferences, Riverpod, existing design tokens.

---

## 背景与兼容性分析

### 两套 Lucide 渲染体系

| | Forui `FLucideIcons` | `elk_icon_picker` `LucideIcons` |
|---|---|---|
| 数据类型 | 标准 `IconData`（font codepoint） | 自定义 `LucideIconData`（SVG 路径数据） |
| 渲染方式 | Flutter `Icon`（icon font） | `LucideIcon`（`CustomPainter`） |
| 图标名 | camelCase 字段名 + 注释中的 kebab-case | `LucideIconData.name`（kebab-case） |
| Lucide 版本 | 1.24.0 | 1.24.0 |

两套包都基于 Lucide v1.24.0，图标名一致。`elk_icon_picker` 的 `LucideIconSelection.name` 返回 kebab-case 字符串（如 `'alarm-clock'`），可以直接映射到 `FLucideIcons.alarmClock`。

### elk_icon_picker API 摘要

```dart
// 选择器入口
Future<IconSelection?> showElkIconPicker(
  BuildContext context, {
  IconSelection? currentSelection,
  Color? backgroundColor,
  Color? iconColor,
  Color? selectedColor,
  Color? selectedIconColor,
  // ... 其他主题参数
});

// 返回值
sealed class IconSelection {}
class LucideIconSelection extends IconSelection {
  final LucideIconData data;
  String get name => data.name;  // kebab-case, e.g. 'house'
}
```

### 已知限制

1. **Sheet 标题硬编码**：`showElkIconPicker` 内部 `"Select Icon"` 为硬编码英文字符串，无法通过参数自定义。后续如需中文标题，需使用 `ElkIconPicker` 内联 widget 自建 `FSheet`。
2. **Material 3 依赖**：`showElkIconPicker` 底层用 `showModalBottomSheet`（Material），主题 fallback 走 `ColorScheme`。需通过显式参数传入 Forui 颜色来覆盖。
3. **图标名别名**：Lucide 有 deprecated aliases（如 `alert-triangle` → `triangle-alert`），两套包可能包含不同子集。Bridge map fallback 处理未命中的情况。

## 实现步骤

### Step 1: Bridge Map 生成脚本

**文件:** `scripts/generate_lucide_bridge.dart`

解析 `forui_assets-0.24.0/lib/src/assets.g.dart`，提取每个图标的 kebab-case 名和 Dart 字段名，生成映射表。

**输入格式**（assets.g.dart 每条记录）:
```dart
/// [![`alarm-clock`](https://.../alarm-clock.svg)]
static const alarmClock = IconData(57402, fontFamily: 'ForuiLucideIcons', ...);
```

**输出格式**（`lib/core/design/lucide_icon_bridge.dart`）:
```dart
// GENERATED CODE - DO NOT MODIFY BY HAND
// Generated by scripts/generate_lucide_bridge.dart
// Source: forui_assets/lib/src/assets.g.dart (Lucide v1.24.0)

import 'package:forui/forui.dart';

abstract final class LucideIconBridge {
  static const Map<String, IconData> _map = {
    'a-arrow-down': FLucideIcons.aArrowDown,
    'a-arrow-up': FLucideIcons.aArrowUp,
    // ... ~1991 entries
    'alarm-clock': FLucideIcons.alarmClock,
    // ...
  };

  static const IconData _fallback = FLucideIcons.circleHelp;

  /// Resolve a Lucide icon name (kebab-case) to [IconData].
  static IconData resolve(String name, {IconData? fallback}) {
    return _map[name] ?? fallback ?? _fallback;
  }

  /// Check if a name exists in the bridge.
  static bool exists(String name) => _map.containsKey(name);

  /// Reverse lookup: find the kebab-case name for an [IconData].
  /// Used to pre-select the current icon in the picker.
  static String? nameOf(IconData icon) {
    for (final entry in _map.entries) {
      if (entry.value == icon) return entry.key;
    }
    return null;
  }
}
```

**脚本核心逻辑:**
```dart
// 1. 读取 assets.g.dart
// 2. 正则匹配: /// [![`<kebab-name>`](url)] 后跟 static const <camelName> = IconData(...)
// 3. 生成 Dart 文件
```

**运行方式:** `dart scripts/generate_lucide_bridge.dart`

**验证:** 生成的 map 条目数应与 `assets.g.dart` 中的 `static const` IconData 数量一致（约 1991 条）。

### Step 2: 图标选择器封装

**文件:** `lib/core/widgets/common/icon_picker_sheet.dart`

封装 `showElkIconPicker`，注入 Forui 主题色，返回 `IconData?`。

```dart
import 'package:flutter/material.dart';
import 'package:forui/forui.dart';
import 'package:elk_icon_picker/elk_icon_picker.dart';
import 'package:luminous/core/design/lucide_icon_bridge.dart';

/// Opens the Lucide icon picker sheet, themed with Forui colors.
///
/// Returns the selected icon as [IconData] (resolved from FLucideIcons),
/// or null if the user dismissed the sheet.
Future<IconData?> showAppIconPicker(
  BuildContext context, {
  IconData? currentIcon,
}) async {
  final colors = context.theme.colors;

  // Convert current IconData to LucideIconSelection for pre-selection
  IconSelection? currentSelection;
  if (currentIcon != null) {
    final name = LucideIconBridge.nameOf(currentIcon);
    if (name != null) {
      final data = LucideIcons.byName(name);
      if (data != null) {
        currentSelection = LucideIconSelection(data);
      }
    }
  }

  final result = await showElkIconPicker(
    context,
    currentSelection: currentSelection,
    backgroundColor: colors.background,
    iconColor: colors.mutedForeground,
    selectedColor: colors.primary,
    selectedIconColor: colors.primaryForeground,
    searchBarFillColor: colors.secondary,
    tabIndicatorColor: colors.primary,
  );

  if (result is LucideIconSelection) {
    return LucideIconBridge.resolve(result.name);
  }

  return null;
}
```

**注意:** 需要确认 `LucideIcons.byName(String)` 是否存在。如果不存，需要从 `LucideIcons` 的 static 字段中查找。备选方案：维护一个 `Map<String, LucideIconData>` 用于 pre-selection。

```dart
Future<void> _showIconPicker(
  BuildContext context,
  WidgetRef ref,
  RecordQuickAction action,
) async {
  final iconData = await showAppIconPicker(
    context,
    currentIcon: action.icon,
  );
  if (iconData != null) {
    final iconName = LucideIconBridge.nameOf(iconData);
    if (iconName != null) {
      await ref
          .read(quickEntryPreferencesProvider.notifier)
          .setCustomIcon(action.type.name, iconName);
    }
  }
}
```

## 风险与回退

| 风险 | 影响 | 缓解 |
|---|---|---|
| `elk_icon_picker` 包停止维护 | 选择器 UI 无法更新 | bridge map 是独立生成的，渲染不依赖该包；可随时替换选择器 UI |
| 两包 Lucide 版本不一致 | 部分图标名无法映射 | bridge map fallback 到 `circleHelp`；版本对齐后重新生成 |
| 生成脚本路径变化 | 重新生成失败 | 脚本读取 pub cache 路径，可通过参数传入 |
| `elk_icon_picker` 内部用 Material 3 | 视觉与 Forui 不完全统一 | 通过显式参数注入 Forui 颜色 |

**回退方案:** 删除 `elk_icon_picker` 依赖 + `lucide_icon_bridge.dart` + `icon_picker_sheet.dart` + revert preferences 改动即可，无数据迁移问题（SharedPreferences 中的 `customIcons` key 不存在时走默认图标）。
