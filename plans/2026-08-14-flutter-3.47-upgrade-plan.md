## 二、已验证可行（V）

### V1. SDK 约束满足
官方 releases JSON 确认 3.47.1 捆绑 **Dart 3.13.1**，项目约束 `>=3.12.0 <4.0.0` 满足运行；若启用 Dart 3.13 语言特性，需将项目及 `generated/lucent_api` 的 SDK 下限提高到 `>=3.13.0`。

### V2. Android built-in Kotlin 预迁移已完成
- `android/gradle.properties` 已有 migrator 写入的 `android.newDsl=false` + `android.builtInKotlin=true`
- `android/app/build.gradle.kts` plugins 块仅 `com.android.application` + `dev.flutter.flutter-gradle-plugin`，**未 apply KGP**
- 官方应用迁移指南（migrate-to-built-in-kotlin/for-app-developers）：builtInKotlin=true 即走 built-in Kotlin 路径，需 AGP 9.0.0+
- 剩余动作（见步骤 4）：settings.gradle.kts 删 KGP 声明、AGP→9.1.0、wrapper→9.3.1

### V3. iOS UIScene 已就绪（Xcode 27 强制无影响）
- `ios/Runner/Info.plist` 有 `UIApplicationSceneManifest` → `$(PRODUCT_MODULE_NAME).SceneDelegate`
- `ios/Runner/SceneDelegate.swift` 存在；AppDelegate.swift 已是 `FlutterImplicitEngineDelegate` 模式
- 本机 doctor 显示 `enable-uiscene-migration` 特性已开启；fluwx pubspec 已配 `scene_delegate: true`

### V4. 工具链与验证边界
- Android SDK 36.1.0 + build-tools 36.1.0 + Java 21（AGP 9 要求 ≥17 ✅），licenses 已接受
- VS 2026 Build Tools + Win10 SDK 26100 → 可本地构建 Windows 桌面
- **无 Xcode**：iOS/macOS 只能改配置，构建与实机验证必须外部 Mac
- ⚠️ doctor 的 Network resources 检查超时（4.5 分钟）→ `flutter upgrade` 前先确认 GitHub 连通

### V5. CI 改动点
- `.github/workflows/flutter-ci.yml:32` 与 `luminous-cd.yml:52`：`flutter-version: 3.44.0` → `3.47.1`
- CI（ubuntu）流水线：arb merge → bootstrap generated sources → build_runner → drift web worker → analyze → test --coverage →（main push 时）release APK
- → **AGP 9 / 老插件兼容性由 CI 的 release APK 构建验证**，不需要先有真机

### V6. 依赖版本结论（pub.dev changelog 核查）
必升（与 3.47 直接相关）：
- `jpush_flutter`：caret `^3.5.0` 自动解析到 **3.5.1**（2026-08-12 发布，专修 Gradle 9 `jcenter()` 报错）——刷新 lockfile 即可
- `health`：`^13.3.1` → **13.3.2**（把 iOS 最低提到 15.0，与本次目标一致）

## 三、未验证（U）

### U1. fluwx 5.7.5 → 6.0.2（风险最高）
- changelog：6.0.0 加 iOS UISceneDelegate 支持 + iOS 转 SwiftPM + Android KTS/KGP；6.0.1 修 `FlutterSceneDelegate` 微信冷启动回调（issue #770）；6.0.2 修 Android Kotlin 构建配置
- 代码面：`lib/features/auth/data/datasources/wechat/mobile_auth_client_fluwx.dart` 仅 1 个文件，用 `Fluwx()` / `registerApi` / `authBy(NormalAuth)` / `addSubscriber` / `WeChatAuthResponse`（5.x 新式 API，6.x Dart API 兼容性未核实）
- 验证：bump 后 `flutter analyze`；真机微信登录 + 分享 + **App 冷启动回调查**；pubspec 的 pin 注释（"requires exact version match"）需按 6.x 情况重写

### U2. AGP 9.1.0 + Gradle 9.3.1 + built-in Kotlin
- 官方：AGP 9.0 起 apply KGP 直接编译报错；Flutter 有**临时兼容层**兜底（未来版本移除）
- 风险点：`jpush_flutter` / `paddle_ocr_native` / `mobile_scanner` 内部若 apply KGP 会在 AGP 9 下报错
- 验证：`flutter build apk --release` 本地 + CI；插件若报错按官方 issue 模板上报，且可回退到「暂不升 AGP 8.11.1」（仅警告，可构建）

### U3. Impeller 桌面默认
- 3.47 起 Windows/Linux/macOS 默认 Impeller（消除 shader jank）；项目未设 impeller switch，直接吃新默认
- 验证：`flutter build windows` 通过 + 运行冒烟（forui / window_manager / flutter_secure_storage 桌面表现、Wide Gamut 渲染）

### U4. l10n 生成模板与 Dart 3.13 变更
- 3.47 的 gen-l10n 输出模板可能变化；Dart 3.13 changelog 因网络限制未能核实（raw.githubusercontent 不可达）
- 验证：merge + gen-l10n 后 `git diff` 审查生成文件；以 analyze 零基线兜底（升级后任何新告警即升级引入）

### U5. iOS/macOS 构建（无本地环境）
- 本机无 Xcode、CI 无 Apple 任务 → 需外部 Mac 验证：`pod install` + xcodebuild + 真机（微信登录、JPush、health 授权）
- 本阶段最小交付：pbxproj/Podfile 配置正确 + 文档标注待 Mac 验证

### U6. flutter_lints 6.0.0 新 lint
- 新增 `strict_top_level_inference`、`unnecessary_underscores`（min Flutter 3.32，兼容）
- 验证：analyze 后告警少则直接修；多则评估是否拆分处理

## 四、执行步骤（顺序）

1. 前置：确认网络（`git -C D:\flutter fetch --dry-run` 或等价检查）；升级分支已基于当前 `refactor` 完成变基
2. `flutter upgrade`（stable → 3.47.1）+ `flutter doctor` 复检
3. pubspec：`fluwx` → `^6.0.2`（更新注释）、`health` → `^13.3.2`；`flutter pub get`（jpush 自动 3.5.1）
4. Android：`settings.gradle.kts`（AGP 8.11.1→9.1.0、删 KGP 2.2.20 声明）、gradle-wrapper 8.14→9.3.1；按官方指南给 `app/build.gradle.kts` 加 `kotlin { compilerOptions { jvmTarget = JVM_17 } }`（以构建报错为准）
5. iOS/macOS 部署目标（V8 清单）
6. `flutter analyze` → `flutter test` → `dart run scripts/check_doc_coverage.dart --warning-only`
7. l10n 重生成 + diff 审查（U4）
8. 构建冒烟：`flutter build apk --release`（本地）→ `flutter build windows` → `flutter build web`
9. 更新 2 个 CI workflow 的 flutter-version → push → **CI 全绿（release APK = AGP 9 验证门禁）**
10. 真机验证（需设备）：微信登录/分享（含冷启动）、JPush 注册、mobile_scanner 扫码、health 读取、paddle_ocr
11. 收尾：迁移日志追加 `docs/03-logs/migration-log/2026-08-14.md`（append，不覆盖）、`docs/00-current/` 更新；本计划完成并验证后删除文件、更新 `plans/README.md` 索引

## 六、风险与回退策略

1. **网络**：doctor 网络检查曾超时。`flutter upgrade` 失败 → 重试 / 手动 `git fetch` + checkout 3.47.1；最坏 `flutter downgrade` 回 3.44.0
2. **老插件在 AGP 9 下编译失败**：Flutter 临时兼容层兜底；仍失败 → 保持 AGP 8.11.1（可构建仅警告）或等插件更新，不阻塞其余改动
3. **fluwx 6.x Dart API 不兼容**：改动面仅 1 文件，可回退 5.7.5 + 恢复旧 pin
4. **真机不可用**：先合并配置 + CI 绿的部分，真机项记 TODO 阻塞合并
5. **iOS/macOS 无验证环境**：pbxproj 改动保持最小（仅部署目标），文档标注待 Mac 验证
