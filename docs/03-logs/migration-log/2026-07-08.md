- **问题**：`mock_repository.dart` 中 `previewDashboard` 和 `_signedOutDashboard` 使用固定时间戳 `'2026-07-07T14:32:00.000Z'`，演示时产生"报告生成于过去"的错觉。

- **文件**：`lib/features/report/data/repositories/mock_repository.dart`

- **修复**：改为空字符串 `''`，UI 格式化器已有 `DateTime.tryParse` + null 返回 `''` 的保护。
- **文件**：`lib/features/report/domain/entities/dashboard.dart`

### P2-1: 重复空值检查模式 (LUM-2026-0708-04)

- **问题**：`remote_data_source.dart` 中约 17 处 `if (body == null) throw ...` 重复模式。
- **修复**：提取 `_requireBody<T>(T? body, String message)` 私有方法，每处从 3 行简化为 1 行。
- **文件**：`lib/features/auth/data/datasources/remote_data_source.dart`

### P2-2: debugPrint 残留 (LUM-2026-0708-05)

- **问题**：`login_form_provider.dart` 中 9 处 `debugPrint` 调试日志，可能泄露敏感信息。
- **修复**：移除全部 `debugPrint` 调用（catch 块已有 `LucentErrorMapper` 提取用户可见错误）。
- **文件**：`lib/features/auth/presentation/providers/forms/login_form_provider.dart`

### P2-3: 日期格式化硬编码 (LUM-2026-0708-06)

- **问题**：`ui_formatters.dart` 用 `locale.startsWith('zh')` 手动切日期格式，不支持 zh-TW/zh-HK 等变体。
