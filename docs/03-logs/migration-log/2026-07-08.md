## Luminous — OpenAPI 生成器迁移：dart-dio → openapi_retrofit_generator

- **目标**：用 `openapi_retrofit_generator` 替代旧的 `dart-dio` 生成器，消除 700+ 行清理脚本 `tool/regenerate_lucent_openapi.dart`，将生成包从 `packages/lucent_openapi/` 迁移到 `generated/lucent_api/`。
- **背景**：旧生成器需要大量后处理脚本来修复 enum 默认值、nullable map 语法、缺失的 API 导出等问题。新生成器原生处理这些问题，无需后处理。
- **迁移内容**：
  - 新建 `generated/lucent_api/` 包，配置 `pubspec.yaml`、`openapi_generator.yaml`、`build.yaml`、`analysis_options.yaml`。
  - 新生成器生成 Retrofit + json_serializable 风格的 API 客户端，方法签名直接返回 DTO 而非 `Response<T>` 包装。
  - 删除旧包 `packages/lucent_openapi/` 和 700+ 行清理脚本 `tool/regenerate_lucent_openapi.dart`。
  - 更新 `pubspec.yaml` 依赖路径从 `packages/lucent_openapi` 改为 `generated/lucent_api`。
- **代码适配**：
  - `dio_client.dart`：使用新的 `LucentClient` 和 `HealthApi` 替代旧的 `AppApi`。
  - `network_providers.dart`：更新 API provider 以匹配新生成器的方法签名。
  - 全局替换 `package:lucent_openapi/lucent_openapi.dart` → `package:lucent_api/api/export.dart`。
  - DTO 访问模式调整：`response.data?.data` → `response.data`（新生成器返回扁平 DTO）。
  - Enum 访问从 `.value` 改为 `.json`（新生成器使用 `@JsonEnum` + `.json` 属性）。
  - API 调用参数名从 `dtoName:` 改为 `body:`（Retrofit `@Body()` 约定）。
  - 测试文件中 fake API 类从 `extends` 改为 `implements`，方法签名匹配新的直接返回类型。
- **文档更新**：
  - `README.md`、`AGENTS.md`、`CONTRIBUTING.md`、`docs/02-reference/OpenApi_Client.md` 等。
  - `.gitattributes`、`.gitignore` 路径更新。
  - `tool/verify_lucent_openapi_sync.dart` 路径和说明更新。
- **验证**：`flutter analyze` — 零 error 级别问题。
