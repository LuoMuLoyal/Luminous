# Migration Log — 2026-08-28

## fix(l10n): 修复 ARB 元数据 key 与字符串 key 不匹配导致的参数顺序错乱

- 根因：`ff4b27df`（`refactor(review): report→review 全量改名`）将 ARB 字符串 key 从 `reportReview...` 改为 `reviewReview...`，但 `@` 前缀的元数据 key（`@reportReview...`）未同步修改，导致 gen-l10n 找不到元数据，方法参数从声明顺序变为字母序。
- `lib/l10n/src/review_zh.arb`、`lib/l10n/src/review_en.arb`：将 19 处 `@reportReview...` 元数据 key 全部改为 `@reviewReview...`，与字符串 key 对齐。
- `dart scripts/arb_tools.dart merge` + `flutter gen-l10n` 重新生成后，方法签名恢复为元数据声明的逻辑参数顺序（如 `reviewReviewChangeOutcomeDetail(String from, String to, int count)` 而非字母序 `(Object count, Object from, Object to)`）。
- 调用方代码（`key_changes.dart`、`next_step.dart`、`what_happened.dart`）参数顺序无需修改，保持原来的逻辑顺序。

## fix(review): 修复 Map 泛型不变性导致嵌套 Map 读取失败

- `lib/features/review/presentation/utils/review_formatters.dart`：`reviewArgMap` 和 `reviewArgMapList` 因 Dart 泛型不变性（`Map<String, Object>` 不是 `Map<String, dynamic>` 的子类型），在字面量或 JSON 解码的嵌套 Map 上返回 null/空列表。改为先检查 `is Map<String, dynamic>`，再 fallback 到 `is Map` 后 `Map<String, dynamic>.from()` 转换。
