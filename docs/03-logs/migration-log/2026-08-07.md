- `lib/features/auth/data/datasources/auth.dart`

### 5. `MedicationQuickBatchResult.errors` 字段移除

- `lib/features/record/presentation/quick_entry/medication_flow.dart`

  - 移除对 `result.errors` 的两处断言。
