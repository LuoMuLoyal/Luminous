## Luminous - 裸 catch 修复（全量）

- 背景：2026-07-03 审查报告标记裸 catch 吞没异常为最严重问题（20+ 处完全空 catch / 无日志 catch）。
  本次对全项目 `lib/` 下所有裸 catch 块添加 `debugPrint` 日志，将 `catch (_)` 改为 `catch (e)` 并记录错误。
- 规则：
  - `catch (_) {}` → `catch (e) { debugPrint('...'); }`
  - `catch (_) { /* 逻辑 */ }` → `catch (e) { debugPrint('...'); /* 原逻辑保留 */ }`
  - `catch (error) { /* 逻辑 */ }` → `catch (error) { debugPrint('...'); /* 原逻辑保留 */ }`
  - 若文件无 `flutter/foundation.dart` 或 `flutter/material.dart` 导入，则补充 `import 'package:flutter/foundation.dart';`
- 验证：`flutter analyze` — No issues found!
