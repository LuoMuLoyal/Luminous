## Luminous — 依赖清理与图片压缩接入

- **目标**：移除无用依赖 `cupertino_icons`，引入 `flutter_image_compress` 并在图片上传场景接入压缩逻辑。
- **评估纠正**：原计划同时移除 `collection`，但搜索发现 11 个文件直接 `import 'package:collection/collection.dart'`（使用 `firstOrNull` 等），保留不动。
- **变更内容**：
  - `pubspec.yaml`：删除 `cupertino_icons: ^1.0.8`（零引用，`uses-material-design: false` + forui `FLucideIcons` 全面替代）；新增 `flutter_image_compress: ^2.4.0`。
  - 新建 `lib/core/utils/image_compressor.dart`：`AppImageCompressor` 静态工具类，提供 `compressForUpload`（1280px / JPEG 85%）和 `compressForAiRecognition`（1920px / JPEG 90%）两个预设；Web 平台 fallback 返回原始 bytes；任何压缩异常 fallback 返回原始 bytes 不阻塞用户。
  - `lib/features/record/presentation/pages/create.dart`：`onPickImage()` 在 `readAsBytes()` 后插入 `AppImageCompressor.compressForUpload()`，`contentType` 固定为 `image/jpeg`。
  - `lib/features/record/presentation/pages/edit.dart`：同上。
  - `lib/features/scan/presentation/pages/box_scan.dart`：AI 识别路径在 `readAsBytes()` 后插入 `AppImageCompressor.compressForAiRecognition()`；OCR 路径不压缩（ML Kit 直接处理文件路径，压缩会降低识别精度）。
