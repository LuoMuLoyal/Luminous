# Migration Log — 2026-08-15

## fix(network): 认证拦截器回调保护与刷新失败日志

- `onSessionExpired` 回调包 try-catch：回调抛异常时记录日志后继续 `handler.next`，原请求不再挂起。
- token 刷新失败（DioException 与非 Dio 异常）记录 endpoint/statusCode 日志后返回 null，不再静默吞掉，便于生产排查。

## refactor(network): requireData 统一信封解包

- `envelope.dart` 新增 `requireData<T>(data, {operation})`：空响应错误消息携带 API 操作名，替代裸 `!` 崩溃。
- 替换 12 个数据层文件 25+ 处 `response.data!.data` 裸解包（含 assistant openConversation 的双层 `!`）。
- 调用点经 EnvelopeInterceptor 已保证信封非空，requireData 仅把失败路径变为可诊断的 StateError。

## fix(auth): 登出失败仍清除本地会话

- `logout()` 改 try-finally：登出请求 500/超时失败时本地 session 也强制清除，避免 token 残留。
- `_requireBody` 增加 operation 参数（22 处调用点带 API 名），空响应 StateError 可定位请求。
- 提取 `_trimOrNull` helper，收敛 8+ 处 trim + 空值判断重复（login/register/deleteAccount 与各 OAuth 方法）。

## fix(health-data): 去重分页循环页数上限

- `while(true)` 改为有界循环（每日期最多 100 页，500×100=5 万条记录上限），空页提前退出：后端 total 异常或页大小异常时不再无限请求 API。

## fix(record): 详情页分析轮询防重入与退避

- `Timer.periodic` 改为链式单次 Timer：invalidate 后 await provider future 覆盖整个请求周期，请求超时不再堆积并发。
- 失败按指数退避（5s → 10s → 20s → 30s 上限），成功回到基础间隔，dispose 照常取消。
