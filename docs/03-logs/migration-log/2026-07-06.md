## Record 页面 UI 修复（第二轮）— 过滤器横向布局 + primary 按钮黑底黑字

### 1. 过滤器纵向布局问题

- **问题**：标准 `FButton` 默认 `mainAxisSize: MainAxisSize.max`，在 `Wrap` 中每个按钮
  撑满可用宽度，导致过滤器变成纵向排列。
- **修复**：为 `_FilterChip` 的 `FButton` 添加 `mainAxisSize: MainAxisSize.min`，
  使按钮按内容宽度排列，恢复横向 `Wrap` 布局。
- **文件**：`lib/features/record/presentation/widgets/sections/record_mobile_filter.dart`

### 2. primary FButton 黑底黑字问题

- **根因**：Forui 的 `FTypography` 中每个 `TextStyle`（如 `typography.body.md`）都携带
  `color: colors.foreground`（近黑 #0A0A0A）。当 `Text` widget 使用 `AppTypographyToken`
  的 style 时，返回的 `TextStyle` 包含这个 color，会覆盖 `FButton` 通过
  `DefaultTextStyle.merge` 设置的 `colors.primaryForeground`（近白 #FAFAFA），
  导致 primary 按钮（黑底）上的文字也是黑色，呈现"全黑"外观。
- **修复**：
  - `RecordHeaderActionChip`（`record_components.dart`）：将 `Text` 的 style 从
    `AppTypographyToken.level5.body(context).copyWith(fontWeight: FontWeight.w700)`
    改为 `TextStyle(fontWeight: FontWeight.w700)`，不携带 color，
    让 `FButton` 的 `DefaultTextStyle` 提供 `colors.primaryForeground`。
  - `MedicineHeaderActionChip`（`medicine_workspace_parts.dart`）：同样修复。
  - FAB（`record_page.dart`）：添加 `mainAxisSize: MainAxisSize.min` 防止按钮撑满宽度。
  - `_QuickRecordNoteButton`（`record_quick_entry_panel.dart`）：同样移除 `AppTypographyToken`
    style，改为 `TextStyle(fontWeight: FontWeight.w700)`，让 ghost 变体的前景色通过
    `DefaultTextStyle` 正确传递。
- **影响文件**：
  - `lib/features/record/presentation/widgets/shared/record_components.dart`
