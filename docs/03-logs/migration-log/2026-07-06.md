### 后续修复：18 个 pre-existing 测试失败

对之前标记为 pre-existing 的 18 个测试失败进行根因分析和修复，全部通过。

#### 1. 路由常量迁移导致的测试不匹配

- `app_back_button_test.dart`：`AppBackButton` 默认 `fallbackRoute` 从 `'/today'` 改为 `AppRoutes.home`（`'/'`），测试路由表需同步更新。
- 修复：测试路由表从 `/today` 改为 `/`，断言文本从 `'Today fallback'` 改为 `'Home fallback'`。

#### 2. Provider 测试缺少 repository override

- `today_dashboard_provider_test.dart`：`ProviderContainer()` 未覆盖 `todayRepositoryProvider`，默认使用 `LucentTodayRepository`（返回 `TodayDashboard.signedOut()`），测试期望 `MockTodayRepository.placeholderDashboard`。
- `auth_session_gate_test.dart`：`_CountingRecordRepository.signedOutDashboard` 直接返回 `RecordDashboard.signedOut()`（空 timeline），但测试期望 `isNotEmpty`。
- 修复：`today_dashboard_provider_test` 添加 `todayRepositoryProvider` override；`_CountingRecordRepository.signedOutDashboard` 改为委托 `MockRecordRepository`。

#### 3. pumpAndSettle 超时（shimmer 持续动画）

- 根因：shimmer 骨架屏动画持续运行，`pumpAndSettle()` 永远无法达到空闲状态。
- 影响文件：`shell_page_test.dart`、`today_ai_card_test.dart`、`mine_page_test.dart`、`medicine_page_test.dart`。
- 修复：将受影响测试中的 `pumpAndSettle()` 替换为 `pump(Duration(milliseconds: 500))`。

#### 4. 真实 Dio API 调用导致 pending timer

- 根因：部分 widget 内部 watch 了会发起真实 Dio 请求的 provider（`todayRecommendationsProvider`、`medicineSafetyTipListProvider`、`notificationUnreadCountProvider`、`healthContextSnapshotProvider`），在测试环境中 Dio 创建的 timer 无法完成。
- 影响文件：`today_ai_card_test.dart`、`shell_page_test.dart`、`medicine_page_test.dart`、`allergy_edit_page_test.dart`、`condition_edit_page_test.dart`、`current_medicine_edit_page_test.dart`。
- 修复：为受影响测试添加对应 provider 的 override（空列表 / mock snapshot / 0），避免真实 API 调用。

#### 5. Signed-out 测试缺少 mineRepositoryProvider override

- `mine_page_test.dart`：signed-out 测试未覆盖 `mineRepositoryProvider`，默认 `LucentMineRepository.signedOutDashboard` 返回 `MineDashboard.signedOut()`（空 `archiveEntries`），导致 `mineArchiveBasicSubtitle` 不存在。
- 修复：添加 `mineRepositoryProvider.overrideWithValue(const MockMineRepository())`。

#### 6. 报告日期范围硬编码

- `report_page_test.dart`：测试硬编码日期 `2026-06-06` ~ `2026-06-12`，但 `MockReportRepository` 使用 `clock.now() - 7天` 动态计算。
- 修复：改为 `DateTime.now()` 动态计算期望日期。

### 最终验证

- `flutter analyze` — No issues found!
- `flutter test` — 896 passed, 0 failed。
