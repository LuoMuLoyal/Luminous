## Patrol 集成测试基础设施修复

### 背景

项目使用 patrol（^4.6.1）作为集成测试框架，但 Windows 下运行 `patrol test` 存在两个阻塞问题：

1. `patrol_cli` 4.4.0 与 `patrol` 4.6.1 版本不兼容（compatibility checker 报错）
2. `adb` 不在系统 PATH 中，patrol_cli 内部的 `adb` Dart 包调用 `io.Process.run('adb', [])` 时找不到可执行文件
3. 缺少 `MainActivityTest.java` androidTest 入口类和 Android Test Orchestrator 配置，导致 `PatrolJUnitRunner` 无法发现 Dart 测试

### 修复

#### 版本升级

- `patrol` 包：`^4.6.1` → `^4.7.1`（pubspec.yaml）
- `patrol_cli`：`4.4.0` → `4.6.0`（`dart pub global activate patrol_cli`）
  - 按 [兼容性表](https://patrol.leancode.co/documentation/compatibility-table)，patrol_cli 4.5.0+ 兼容 patrol 4.7.0+

#### adb PATH 问题

patrol_cli 内部的 `adb` Dart 包直接调用 `io.Process.run('adb', [])`，不搜索 Android SDK 目录。adb 位于 `D:\AndroidStudioSdk\platform-tools\adb.exe` 但不在系统 PATH 中。运行测试时需将该路径临时加入 PATH：

```powershell
$env:PATH = "D:\AndroidStudioSdk\platform-tools;$env:PATH"
```

#### Android Test Orchestrator 配置

**`android/app/build.gradle.kts`**:

- `defaultConfig` 中添加 `testInstrumentationRunner = "pl.leancode.patrol.PatrolJUnitRunner"`
- `defaultConfig` 中添加 `testInstrumentationRunnerArguments["clearPackageData"] = "true"`
- 新增 `testOptions { execution = "ANDROIDX_TEST_ORCHESTRATOR" }`
- `dependencies` 中添加 `androidTestUtil("androidx.test:orchestrator:1.5.1")`

#### MainActivityTest.java

**`android/app/src/androidTest/java/com/dev/luminous/MainActivityTest.java`** — 新建。`@RunWith(Parameterized.class)` 入口类，`@Parameters` 方法中调用 `PatrolJUnitRunner.setUp()` → `waitForPatrolAppService()` → `listDartTests()` 动态发现 Dart 测试，每个 Dart 测试作为参数化测试用例执行。

#### 测试代码修复

**`integration_test/support/e2e_test_helpers.dart`** — `_shellTabForLabel` 的 switch 中添加 `'今日'` 匹配（原仅匹配 `'今天'`），修复 `openTab($, '今日')` 无法识别 ShellTab 导致 fallback 到 `NavigationBar` finder 的问题。

### 验证

- `patrol test --target integration_test/today/today_e2e_test.dart --device emulator-5554`
- 5 个测试全部被发现并执行：2 个通过（assistant entry、tab navigation），3 个失败（时序问题，emulator 渲染慢导致 `settleE2e` 的 6 帧 100ms 不够，需后续调整）

### 运行方式

```powershell
cd Luminous
$env:PATH = "D:\AndroidStudioSdk\platform-tools;$env:PATH"
dart pub global run patrol_cli:main test --target integration_test/today/today_e2e_test.dart --device emulator-5554 --verbose
```

## 集成测试修复与补充

### 背景

`today_e2e_test.dart` 的 5 个测试中 3 个因时序/滚动问题失败。同时项目缺少 Shell 导航和搜索页的独立集成测试。

### today_e2e_test 修复

原测试存在三个问题：

1. **`settleE2e` 时序不足** — 6 帧 × 100ms = 600ms 不够等待 `todayDashboardProvider`（FutureProvider）解析。改用 `pumpUntilFound` 等待 `today-summary-card` 出现后再断言。
2. **SliverList 懒加载** — `today-observation-card` 和 `today-quick-actions-primary` 位于 `CustomScrollView` 的 `SliverList` 底部，模拟器屏幕上看不到，sliver 不构建它们。`find.byKey` 默认 `skipOffstage: true`，永远找不到。改用 `$.tester.drag` 手动滚动后断言。
3. **`scrollUntilVisible` 多 Scrollable 冲突** — `FTileGroup` 内部含 `Scrollable`，导致 `find.byType(Scrollable)` 匹配多个元素，`scrollUntilVisible` 内部 `widget<Scrollable>(scrollable!)` 调用 `.single` 抛 "Too many elements"。改用 `drag` 避免此问题。
4. **登录页断言** — `find.widgetWithText(FilledButton, '登录')` 在 Today 测试中失败。登录页提交按钮使用 `FButton`（Forui），其内部 widget 层级与从 Mine/Report 导航时不同。改用 `find.byKey(const Key('auth-login-submit-action'))` 和 `find.byKey(const Key('auth-login-email-field'))` 断言。
5. **`/record/create` 路由权限** — 未登录用户导航到 `/record/create` 会被路由守卫重定向到 `/login`。新增测试验证此行为。

## Patrol → integration_test 框架迁移

#### 测试代码迁移（24 个文件）

## sqlite3 原生库下载失败修复

### 背景

`sqlite3` 包 v3.3.4 在 native assets 构建钩子中尝试从 GitHub 下载预编译的 `sqlite3.x64.windows.dll`。Windows 上 Dart 的 `HttpClient` 存在 TLS 证书问题（dartbug.com/52266），导致下载因"信号灯超时时间已到"失败。此错误在 `git commit` 触发 pre-commit hook 执行 `flutter analyze` 时出现，阻塞所有提交。

### 修复

- **即时修复**：使用 PowerShell 的 `Invoke-WebRequest`（使用 Windows 证书存储）下载 `sqlite3.x64.windows.dll`，放入 `.dart_tool/hooks_runner/shared/sqlite3/build/download-563a01a5/sqlite3.dll` 缓存目录，SHA256 哈希验证通过。
- **可复用脚本**：新增 `tool/fetch_sqlite3_binary.ps1`，封装预下载逻辑，支持 Windows（x64/arm64/ia32）和 Android（arm/arm64/x64/ia32）多目标，带 SHA256 哈希校验和缓存命中检测。`flutter clean` 清除缓存后可重新运行此脚本恢复。

### 使用方式

```powershell
cd Luminous
./tool/fetch_sqlite3_binary.ps1                          # 仅 Windows x64（默认）
./tool/fetch_sqlite3_binary.ps1 -Target "windows-x64,android-arm64"  # 多目标
```

### 验证

- `flutter analyze` — No issues found（构建钩子命中缓存，跳过下载）
- `dart run tool/check_doc_coverage.dart --warning-only` — 无需更新文档
