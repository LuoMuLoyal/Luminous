## Luminous - Report 移动端 readiness-first 重构

### 背景

原报告页在移动端同时暴露“登录查看”“数据不足”“当前显示上次报告快照”“生成总结”“导出摘要”“健康模式分析”等多套信号，首屏没有单一主问题，用户难以判断自己到底是不能看、不能生成，还是只在看预览。

### 修改

- **report domain / repository**
  - `ReportDashboard` 新增 `generatedAt`
  - `LucentReportRepository` 将 Lucent report dashboard DTO 的 `generatedAt` 映射进 domain
  - mock / 测试 dashboard 同步补齐 `generatedAt`

- **移动端首屏重构**
  - 新增 `readiness_section.dart`
  - 首屏改为单一 `readiness` 主卡，合并：
    - 登录门槛
    - 数据不足说明
    - 生成总结
    - 同步
    - 当前数据更新时间
  - 主卡状态收敛为：
    - `未登录`
    - `已登录 + 数据不足`
    - `已登录 + 数据足够`

- **移动端页面编排重排**
  - 顶部 `ReportTopBar` 仅保留标题、日期范围和时间范围 pill
  - 移动端移除独立 snapshot 卡和顶部第二行按钮组
  - `ReportDashboardView` 移动端重排为：
    - readiness 主卡
    - 报告预览评分
    - 健康趋势预览
    - 重点发现
    - 条件满足后再显示 AI 总结 / 导出摘要 / 健康模式分析
  - 移动端隐藏：
    - 独立数据不足横幅
    - 趋势区内重复的时间范围 pill
    - 首屏指标四宫格
    - 未登录 / 数据不足时的完整导出卡组和模式分析区

- **未登录预览修正**
  - `reportDashboardProvider` 未登录分支改为返回前端 preview dashboard，而不是空白 `signedOut()` 占位
  - readiness 主卡显示真实 `generatedAt` 格式化时间，不再写模糊 snapshot 文案

- **本地化**
  - 新增 report readiness 相关 ARB 文案：
    - badge
    - 标题 / 描述
    - 数据更新时间
    - 缺失指标提示
    - locked features hint
    - continue recording CTA
  - `flutter gen-l10n` 重新生成

### 1. Medicine 安全检查三层展示

**目标**：安全检查结果不再只有「有风险提示」和「无风险提示」两种状态，改为三层视觉语义。

#### 1.1 风险检查页重构（`risk_check_page.dart`）

- 将 `_MedicineRiskCheckBody` 的扁平展示重构为三层结构：
  - **Tier 1 — 已确认风险（红色）**：当 `result.hasFindings` 时显示，带红色 `_TierBanner` 头部 + 风险提示卡片列表
  - **Tier 2 — 已确认安全（绿色）**：当 `!hasFindings && !hasCoverageGaps` 时显示，带绿色 `_TierBanner` + "已检查 N 种药品，未发现明确风险提示" + "不等于绝对安全"免责声明

- 新增 `_TierBanner` 组件：统一的三层头部横幅，支持 `AppStateTone` 色调（danger/success/warning）
- 保留红旗警告横幅在最顶部

#### 1.2 严重度语义色修正（`copy.dart`）

- `medicineRiskSeverityColor` / `medicineRiskSeveritySoftColor`：

#### 1.3 添加前风险检查弹窗增强（`medicine_add_precheck_dialog.dart`）
