## API 客户端生成器迁移：openapi_retrofit_generator → openapi_generator (dart-dio)

### 背景

`openapi_retrofit_generator` 对 `required: true` + `nullable: true` 字段生成错误（缺少 `?` 后缀），导致编译错误需/运行时风险。用户要求零容忍生成器 bug，决定切换到官方 `openapi_generator` 的 `dart-dio` 生成器。

### 变更内容

- **生成客户端替换**（`generated/lucent_api/`）：用 `openapi_generator` (dart-dio + json_serializable) 重新生成全部 API 和 Model 文件
- **pubspec.yaml**：移除 `retrofit`、`openapi_retrofit_generator`，新增 `copy_with_extension`
- **导出文件**：删除 `lib/api/export.dart`，新增 `lib/lucent_api.dart` 作为统一导出入口；新增 `lib/src/api.dart` 定义 `LucentApi` 类
- **网络层**（`lib/core/network/`）：
  - `dio_client.dart`：新增 `LucentClient` 包装类，通过属性 getter 暴露各 API 实例（`.auth`、`.medicines` 等），保持应用层 `.client.auth.xxx` 访问模式不变
  - `api.dart`：导出路径从 `package:lucent_api/api/export.dart` 改为 `package:lucent_api/lucent_api.dart`
  - `network_providers.dart`：移除未使用的 `lucent_api` 导入
- **应用层批量修复**（`lib/features/`）：
  - 枚举类名：`XxxDtoFieldNameField` → `XxxDtoFieldNameEnum`
  - 枚举值访问：`.json` → `.value`
  - 未知枚举：`$unknown` → `unknownDefaultOpenApi`
  - API 参数名：`body: XxxDto(...)` → `xxxDto: XxxDto(...)`
  - 响应提取：`response.data` → `response.data!.data`（`Response<T>.data` 为 `T?`，需 `!` 解包后再取 `.data`）
  - 保留字字段：`source` → `source_`、`valuesField` → `values`
  - `Lang` 枚举移除：法务文档 API 的 `lang` 参数从 `Lang` 枚举改为 `String?`
  - `Source`/`Scope`/`Range`/`LifecycleState`/`Type` 枚举移除：对应 API 参数改为 `String?`
- **Auth mapper**：`toSessionFromLogin`/`toSessionFromRegister` 参数从 `LoginResponseDto`/`RegisterResponseDto` 改为 `LoginDataDto`/`RegisterDataDto`，直接接收内层 data

### 结果

- `flutter analyze lib`：**0 errors**（完全清洁）
- `flutter analyze test integration_test`：**0 issues found**（mock/helper/API fake 全部适配完成）
- `flutter test`：剩余 13 个运行时 widget/golden 失败，均与 OpenAPI 适配无关（布局/Golden/工具类问题）
