# 2026-07-23 代码审查修复

## TapGestureRecognizer 内存泄漏修复

### 背景

代码审查报告指出注册页 `_TermsAgreementText` 组件作为 `StatelessWidget`，在 `build()` 中创建 `TapGestureRecognizer` 实例但未调用 `dispose()`。每次父组件 rebuild 时旧的 recognizer 无法释放，造成内存泄漏。

### 修复

将 `_TermsAgreementText` 从 `StatelessWidget` 改为 `StatefulWidget`：
- `initState()` 中创建 `TapGestureRecognizer` 实例
- `didUpdateWidget()` 中更新回调（处理父组件 rebuild 时回调变化）
- `dispose()` 中释放 recognizer

**文件:** `lib/features/auth/presentation/pages/register.dart`
