### 1. 🔴 公共分享页错误提示误导用户

- **文件**：`lib/features/report/presentation/pages/clinic_summary_shared.dart`
- **修复**：错误回调从统一显示"链接已过期或失效"改为使用 `LucentErrorMapper.toAppError(error)` 区分错误类型。网络错误（`AppErrorKind.network`）显示"网络连接失败，请检查网络后重试"+ `wifiOff` 图标 + 重试按钮（`ref.invalidate` 重新加载）；其他错误（含 404/410 链接失效）仍显示"链接已过期或失效" + `triangleAlert` 图标，无重试按钮。

### 2. 🟡 PDF 下载逻辑提取为公共工具

- **新增文件**：`lib/features/report/presentation/utils/pdf_download.dart`
- **修复**：提取 `downloadAndSharePdf()` 函数和 `PdfDownloadResult` 枚举，封装 Dio 二进制下载 → 判空 → 写临时文件 → SharePlus 分享的完整流程。`clinic_summary_shared.dart` 和 `clinic_summary_preview_dialog.dart` 的 `_downloadPdf` 方法均改为调用此函数，消除重复代码。差异点（endpoint、文件名前缀、分享标题、是否跳过认证）通过参数传入。

### 3. 🟡 通知列表 hover 状态改用 ValueNotifier

- **文件**：`lib/features/notification/presentation/widgets/shared/list_item.dart`
- **修复**：`_isHovered` 从 `bool` + `setState` 改为 `ValueNotifier<bool>` + `ValueListenableBuilder`。`MouseRegion` 的 `onEnter`/`onExit` 直接设置 `_isHovered.value`，hover 操作按钮区域用 `ValueListenableBuilder` 局部重建，不再触发整个列表项 widget 的 `build`。`dispose` 中调用 `_isHovered.dispose()`。

### 4. 🟡 `_formatDateTime` / `_MetaRow` 提取为公共组件

- **修改文件**：
  - `lib/core/utils/date_format_utils.dart`：新增 `formatDateTimeFull()` 函数（`yMd` + `Hm` 格式）。
  - `lib/features/report/presentation/widgets/shared/components.dart`：新增 `MetaRow` widget（80px 固定 label 宽度的横向键值行）。
  - `lib/features/report/presentation/widgets/shared/clinic_summary_content.dart`：移除私有 `_formatDateTime` 和 `_MetaRow`，改用 `formatDateTimeFull` + `MetaRow`。
  - `lib/features/report/presentation/widgets/dialogs/suggestion_history_detail_sheet.dart`：同上，移除私有重复定义。

### 5. 🟡 分享失败错误消息拼接格式不一致

- **文件**：`lib/features/report/presentation/widgets/dialogs/clinic_summary_preview_dialog.dart`
- **修复**：硬拼接的 `'${l10n.reportExportFailedToast}: ${error.message}'` 改为 l10n 参数化字符串 `l10n.reportExportFailedWithReason(error.message)`，中文显示"导出失败：xxx"，英文显示"Export failed: xxx"，冒号格式由各语言的 ARB 模板控制。

### 6. 登录/注册页 Send Code 失败提示 + 未登录启动进入预览页
