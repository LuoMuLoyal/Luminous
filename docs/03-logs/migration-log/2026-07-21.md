## Luminous — 修复 FHeader.nested 在 ListView 中的布局崩溃

- **问题**：Forui 0.24.x 的 `_RenderNestedHeader.performLayout()` 在收到 tight width 约束（如 `ListView` 给子项的约束）时，会将完整约束传给 prefixes/suffixes，导致它们占满全宽，title 收到 `BoxConstraints(minWidth > maxWidth)` 的无效约束而崩溃。根因是 commit `b7837929`（`refactor(header): 用FHeader替代AppTopBar`）将 `FHeader.nested` 直接放进了原来 `AppTopBar` 所在的 `ListView` 位置，但 `FHeader.nested` 的 `_RenderNestedHeader` 不支持 tight width 约束。
- **方案**：将 `FHeader.nested` 从 `ListView` 中拆出，放到 `Column` 顶部，`ListView` 只包含其余内容。这是 Forui 设计意图的正确用法——`FHeader.nested` 应在 `Column` 顶部或 `FScaffold.header` 中，不应在滚动视图中。
- **删除文件**：`lib/core/widgets/common/tab_top_bar.dart`（临时替代组件，不再需要）。
- **修改文件**：
  - `lib/features/today/presentation/widgets/shared/top_bar.dart`：`TabTopBar` → `FHeader.nested`。
  - `lib/features/today/presentation/widgets/views/dashboard_view.dart`：`_MobileTodayDashboard` 和 `_DesktopTodayDashboard` 从 `ListView(TodayTopBar + ...)` 重构为 `Column(TodayTopBar + Expanded(RefreshIndicator(ListView(...))))`。
  - `lib/features/report/presentation/widgets/shared/top_bar.dart`：`TabTopBar` → `FHeader.nested`。
  - `lib/features/report/presentation/pages/page.dart`：`_ReportMobileShell` 从 `ListView(header + ...)` 重构为 `Column(header + Expanded(RefreshIndicator(ListView(...))))`。
  - `lib/features/mine/presentation/widgets/sections/top_bar.dart`：`TabTopBar` → `FHeader.nested`。
  - `lib/features/mine/presentation/pages/page.dart`：从 `ListView(MineTopBar + ...)` 重构为 `Column(MineTopBar + Expanded(RefreshIndicator(ListView(...))))`。
  - `lib/features/medicine/presentation/pages/page.dart`：`_MedicineMobileShell` 从 `ListView(TabTopBar + ...)` 重构为 `Column(FHeader.nested + Expanded(ListView(...)))`。
- **不受影响**：`RecordPage`（`FHeader.nested` 在 `FScaffold.header` 中）、`DesktopTabShell`（`FHeader.nested` 在 `Column` 中）。
- **验证**：`flutter analyze` 零问题。
