## Luminous Better Auth 客户端同步（Task 7）

Lucent 完成 Better Auth 迁移后，Luminous 按新的 OpenAPI 合同同步认证相关 DTO、数据层、页面与测试，继续只依赖 Lucent JWT access/refresh，不引入 Better Auth cookie/session。

### 合同变更

- 运行 `dart run scripts/bootstrap_generated_sources.dart` 重新生成 `generated/lucent_api/`：
  - `SendVerificationCodeDto.scene` 枚举移除 `resetPassword`，新增 `set-password`。
  - `ResetPasswordDto` 改为 `{ token, password }`（来自邮件重置链接）。
  - `VerifyEmailDto` 改为 `{ token }`（来自邮件验证链接）。
  - `ForgotPasswordDto` 保持 `{ email }`，但后端改为发送重置链接邮件。
