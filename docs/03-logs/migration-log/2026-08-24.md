## Luminous Task 8：Security PIN → 密码再认证

### 后台合同

- 敏感操作（修改邮箱、解绑身份、注销账号、数据导出）由 `POST /auth/account/change-email`、`POST /auth/account/unlink-identity`、`DELETE /auth/account`、`POST /data-export-requests` 等端点统一要求当前账户密码。
- Lucent `PasswordReauthService` 通过 Better Auth `password.verify` 校验密码；失败返回 `AUTH_PASSWORD_INVALID` / `AUTH_PASSWORD_NOT_SET` 等业务码。
- Luminous 不再读取/写入 `SecurityElevationTokenHolder` 或调用 `/settings/security-pin/verify`。
