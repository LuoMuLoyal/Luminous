## Trace 全链路 — Sentry 分布式追踪（方向 1）

### 接入 sentry_dio + W3C traceparent 传播

- `pubspec.yaml` / `pubspec.lock`：新增直接依赖 `sentry_dio ^9.0.0`。
- `lib/main.dart`
  - `options.propagateTraceparent = true`：Sentry 在出站请求注入 W3C `traceparent`，后端 OTel 承接同一条 trace（Sentry + Jaeger + 帮助页「最近请求 Trace ID」展示同一 traceId）。
  - `tracesSampleRate` 由 `release 0.2 / debug 1.0` 统一为 `1.0`：低于 1.0 时未采样请求会带 `sampled='00'`，Lucent OTel（parent-based sampler）会丢弃其 span。
  - `beforeSend` 不再读全局 `TraceContext.lastTraceId`，改为提升 hint 中 per-error `trace_id` 为 tag，消除「最近一次请求」的误导性关联（请求级错误上下文由 SentryDioInterceptor 自动绑定）。
- `lib/core/network/dio_client.dart`：`_dio` 与 `_refreshDio` 均调用 `addSentry(captureFailedRequests: false)`（HTTP 失败已由 Talker→Sentry observer 与框架错误处理器上报，避免重复事件）。
- `lib/app/router.dart`：接入 `SentryNavigatorObserver`，路由导航开启 Sentry 事务、请求成为其子 span；Sentry 未初始化（测试环境）时为 no-op，不产生事务与计时器。
