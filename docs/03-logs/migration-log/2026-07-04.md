## Luminous - 修复通知页返回后 session 过期未同步到 UI

- Time: ~21:10 local time.
- 问题：点击右上角通知进入通知列表再返回 Mine/Today 时，若后台返回 401，`LucentDioClient` 的
  `_shouldRefresh` 走到 `return false`（`lucent_dio_client.dart:234`）后只 reject 错误，
  没有通知 `authSessionProvider`，导致 UI 仍认为已登录，后续请求持续失败或页面表现“卡住”。
- 根因：`lucentDioClientProvider` 创建时未设置 `onSessionExpired` 回调；
  且拦截器只在 token refresh 失败时清理 session，对非 `tokenExpired` 的 401（如 401001 unauthorized）
  或缺少 refresh token 的 401 未清理本地 session。
- 修复：
  - `lib/core/network/lucent_dio_client.dart`
    - 将 `_onSessionExpired` 改为可写，新增 public setter `onSessionExpired`。
    - 调整 `onError`：任何 401（无论是否满足 refresh 条件）都会先 `clearSession()`，再触发回调。
  - `lib/features/auth/presentation/providers/session/auth_session_provider.dart`
    - 在 `AuthSessionNotifier.build()` 中读取 `lucentDioClientProvider` 并设置回调，
      回调内将 `authSessionProvider` 状态重置为未登录（避开 `restore()` 执行期间重复设置）。
  - `test/core/network/lucent_dio_client_test.dart`
    - 更新非 `tokenExpired` 401 与无 refresh token 的用例，断言 session 被清理且回调被调用。
    - 新增 setter 测试，验证构造后仍可接线回调。
- 验证：
  - `flutter analyze lib/core/network/lucent_dio_client.dart lib/features/auth/presentation/providers/session/auth_session_provider.dart`：No issues found!
  - `flutter test test/core/network/lucent_dio_client_test.dart test/auth/ test/notification/ test/mine/mine_page_test.dart`：100/100 passed.
  - 全量 `flutter test --no-pub` 仍有仓库中既有的 UI 测试超时失败（`shell_page_test.dart`、
