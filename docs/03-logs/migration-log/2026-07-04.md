## Luminous - Today 页优先事项 action pill 修复

- Time: ~14:30 local time.
- 问题：模拟器截图 `reference/2026-7-4-14-09` 中，Today 页「今日优先事项」右侧药/水卡片的
  action pill 为黑色无文字块。
- 根因：`lib/features/today/presentation/widgets/sections/today_priority_section.dart`
  的 `_PriorityActionPill` 把文字颜色设为 `colors.primary`，而按钮背景色为 `item.color`
  解析后的 `colors.primary`（浅色主题下为黑色），导致文字与背景同色。
- 修复：
  - 将 action pill 的 `Text` 颜色从 `colors.primary` 改为 `colors.primaryForeground`。
- 测试：`test/today/today_page_test.dart`
  - 新增用例，断言 medication/water priority 卡片中的 action 文字颜色为 `primaryForeground`，
    且无 overflow 异常。
- 文档同步：
  - 更新 `docs/00-current/Current_State.md`。
- 验证：
  - `flutter test --no-pub test/today/today_page_test.dart`：13/13 passed.
