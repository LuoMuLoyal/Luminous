## 🔴 严重修复：DateTime.parse 崩溃风险与重复实现

### 1. 统一安全日期解析工具

- `lib/core/utils/date_format_utils.dart`
  - 新增 `parseDateTimeOrNull`：null / 空 / 畸形 ISO-8601 输入返回 null，永不抛异常（基于 `DateTime.tryParse`）。
  - 新增 `parseDateTimeOrEpoch`：实体必填字段的安全解析，畸形输入回退 epoch，避免应用崩溃。

### 2. auth mapper / datasource 消除裸 `DateTime.parse`

- `lib/features/auth/data/mappers/auth.dart`
  - `createdAt` / `updatedAt` 由 `DateTime.parse` 改为 `parseDateTimeOrEpoch`；`emailVerifiedAt` 改用 `parseDateTimeOrNull`。
  - 删除无 try-catch 保护的本地 `_parseOptionalDateTime`。
- `lib/features/auth/data/datasources/auth.dart`
  - 删除与 mapper 重复且实现不一致的本地 `_parseOptionalDateTime`，统一调用公共工具。
  - `linkedAt` / `createdAt` / `updatedAt` 改用 `parseDateTimeOrEpoch`；`emailVerifiedAt` / `lastLoginAt` 改用 `parseDateTimeOrNull`。

## 🟡 警告处理
