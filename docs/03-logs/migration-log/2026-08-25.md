## 错误处理收尾（阶段 1 + 3 + 4 + 6 剩余）

### TaskEither monad 语义修复（A-1 ~ A-4）

- `lib/features/auth/data/datasources/auth.dart`: `refreshSession` 内部
  `throw value` 反模式改为 `flatMap` 链——先 `tryCatch` 刷新 token，再
  `flatMap` 到 `fetchAccount().map(...)`，消除 monad 内部 throw。
- `lib/features/auth/presentation/providers/account.dart`: 删除 `_resolve`
  方法，`_run` 改为接受 `TaskEither<LucentFailure, T>` + `FutureOr<void> Function(T)`
  回调，用 `is Left` / `as Right` 直接处理 Left/Right，不再依赖 try/catch + throw。
  `startWechatIdentityLink` 中的 `_resolve` 调用改为 `.run()` + `switch` 模式。
- `lib/core/network/interceptors/retry_interceptor.dart`: `DioException` 构造
  添加 `message: err.message`，保留原始错误消息。
- `lib/core/network/interceptors/auth_interceptor.dart`: 裸 `catch (e, st)` 改为
  `on Exception catch (e, st)`，让 `AssertionError`/`TypeError` 等编程错误穿透。

### StateError 分类处置（C-1 ~ C-11）

  编程前置条件，release 模式用 `!` 断言）。
