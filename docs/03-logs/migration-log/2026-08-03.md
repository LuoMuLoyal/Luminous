## Markdown 渲染样式统一与场景区分

来源：`plans/2026-08-03-markdown-rendering-style.md`（子代理逐任务执行，审查通过；实施完毕文件已删）

### 新增样式工厂（唯一入口）

- `lib/core/design/markdown_style.dart`：`MarkdownStyle` 抽象类提供两套预置 `MarkdownStyleSheet`：
  - `legal(context)`：正式文档（法律文书详情、帮助页 FAQ）——正文 level4/行高 1.7、h1-h3 强层级递减、中性引用左条。
  - `ai(context, {background, paragraphWeight, emphasizeLinks})`：AI 生成内容（聊天气泡、Today 摘要/建议、报告总结）——正文 level4/行高 1.6、primary 引用左条与列表 bullet、代码块圆角 + 等宽字体 + 主题背景；`background` 使代码背景随气泡/容器底色自适配，`paragraphWeight` 支持摘要 w600 / 报告总结 w700 覆盖。
- 两套均基于 `TypographyToken` / `Spacing` / `RadiusTokens` 与 Forui `FColors` 解析；代码块/行内代码/表格/分割线/链接统一接入主题 token，深浅色自动适配。
- `lib/core/design/design.dart` 追加导出。

### 6 处渲染点迁移

- legal 2 处：`lib/features/legal/presentation/pages/detail.dart`（法律文书详情）、`lib/features/settings/presentation/pages/help.dart`（FAQ 答案）。
- ai 4 处：`lib/features/assistant/presentation/widgets/shared/message_bubble.dart`（气泡背景传入 `background`）、`lib/features/today/presentation/widgets/sections/summary.dart`（摘要 w600）、`lib/features/today/presentation/widgets/sections/suggestion_interactive.dart`（reason 默认 + boundary muted 变体）、`lib/features/report/presentation/widgets/sections/ai_summary.dart`（总结 w700）。

### 与计划差异（以 flutter_markdown_plus 实际 API 为准）

- `MarkdownStyleSheet` 无独立 `codeblock` TextStyle 字段，代码块文字复用 `code`；无 `tableHeadDecoration`，实际字段为 `tableHeadCellsDecoration`。
- Forui `FColors` 无 `borderStrong`，legal 引用左条用 `colors.border`。
- `listBullet` 为 `TextStyle?` 而非 `Color`，传 `body.copyWith(color: primary)`。
