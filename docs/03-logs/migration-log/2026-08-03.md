### 错误映射去重（🟡 2 条）

- `lib/core/network/interceptors/error_interceptor.dart`
  - `ErrorInterceptor` 删除与 `error_mapper.dart` 逐字重复的 `_fallbackMessage`、`_errorCodeFromDioType`、envelope 解析、requestId/traceId 提取逻辑，改为委托 `LucentErrorMapper.fromObject()` 并仅做 `DioException` 再包装。

### Sentry 内部 API 依赖移除（🟡）

- `lib/core/network/dio_client.dart`
  - `_isSentryPropagatingTraceparent()` 由 `HubAdapter()` + `hub.options.propagateTraceparent`（`invalid_use_of_internal_member`）改为只读公开 API `Sentry.isEnabled`：`main.dart` 在 Sentry 初始化时总是开启 `propagateTraceparent`，故该标志等价；`HubAdapter` / `Sentry.currentHub` 均属 SDK 内部 API，升级 minor/patch 可能编译失败。

### 生产采样率下调（🟡）

- `lib/main.dart`
  - `tracesSampleRate = 1.0` 改为 `tracesSampler`：`/sync/`、`/auth/` 关键路径保持 1.0（保证 W3C `traceparent` 携带 `sampled=01`，后端 OTel parent-based sampler 承接 span），其余请求 release 下 10% 采样、debug 下 100%。降低移动端电量/流量/内存与 Sentry 配额消耗。

### 待同步队列（🟡 2 条）
