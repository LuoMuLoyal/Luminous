# 2026-08-29 迁移日志

## 代码审查修复（基于 08-28 审查文档）

### ShellPage Column 布局修复
- `lib/features/shell/presentation/page.dart`: 移除 `mainAxisSize: MainAxisSize.min`，
  让 Column 使用默认 `MainAxisSize.max`，与 `Expanded` 子组件协调一致，
  避免 debug 构建中的 RenderFlex 警告和 release 下 content 区域被压缩。

### 数据库 schema v5 迁移
- `lib/core/database/database.dart`: schemaVersion 从 4 提升到 5，
  新增 `if (from < 5)` 迁移步骤调用 `m.renameTable()` 将
  `report_dashboard_cache_entries` 重命名为 `review_dashboard_cache_entries`，
  修复已升级到 v4 的用户因表名不匹配导致缓存查询静默失效。

### LucideIconBridge 反查性能优化
- `scripts/generate_lucide_bridge.dart` + `lib/core/design/lucide_icon_bridge.dart`:
  新增 `static final _reverseMap` 预计算反查 Map，`nameOf()` 从 O(N) 线性扫描
  优化为 O(1) Map 查找。重新生成了 bridge 文件（2030 entries）。

### icon picker 国际化修复
- `lib/core/widgets/common/icon_picker_sheet.dart`: 将硬编码的中文分类标签
  和英文搜索提示改为通过 `AppLocalizations` 获取。
- 新增 `IconPickerCategory` 枚举，每个值提供 `label(l10n)` 方法。
- 新增 l10n key: `iconPickerCategory{Food,Health,Status,Body,General}`、
  `iconPickerSearchHint`、`iconPickerEmpty`。
  - 修改文件: `lib/l10n/src/common_zh.arb`、`lib/l10n/src/common_en.arb`。

### SoftIcon 类型校验修复
- `lib/core/widgets/common/soft_icon.dart`: 将 `else` 分支的 `icon as IconData`
  强制 cast 替换为 `else if (icon is IconData)` 类型检查 + assert 显式失败路径，
  当传入类型不匹配时不再抛 TypeError，而是触发 assert 并渲染 fallback 图标。
