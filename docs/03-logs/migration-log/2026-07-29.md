# 2026-07-29 迁移日志

## 用药模块 — 审查问题修复

### 修复 1：提醒表单 firstWhere 崩溃防护

- **文件**: `lib/features/medicine/presentation/widgets/reminder/form_body.dart`
- **变更**: `FSelect.rich` 的 `format` 回调中 `firstWhere` 改为 `firstWhereOrNull` + `?.displayName ?? ''`
- **原因**: 药品被删除或标记为非当前后，`selectedMedicineId` 仍保留旧值，`firstWhere` 会抛出 `StateError` 导致 widget 构建崩溃

### 修复 2：fetchWorkspace getRecords() 错误降级

- **文件**: `lib/features/medicine/data/repositories/lucent_workspace.dart`
- **变更**: `riskCheckRepository.getRecords()` 调用包裹 try-catch，失败时记录日志并降级为 `null`（`riskCheckRecords` 字段已为 nullable）
- **原因**: 同方法中 dose logs 和 reminders 都有独立的 try-catch，`getRecords()` 是新增的网络依赖但缺少错误保护，网络失败会导致整个用药仪表盘白屏

### 修复 3：风险检查时间格式化跨天显示

- **文件**: `lib/features/medicine/presentation/widgets/shared/copy.dart`
- **变更**: `medicineRiskCheckFormatTime` 增加可选 `now` 参数，当检查时间不是今天时显示 `MM-dd HH:mm` 而非仅 `HH:mm`
- **原因**: 跨天检查只显示 "14:30" 会让用户误以为是今天的检查。`mobile_safety.dart` 的 `isStale` 守卫不完全覆盖此问题（`stale` 由后端在上下文变更时设置，"not stale" ≠ "today"）
- **影响调用点**: `check_tab_content.dart:197`、`mobile_safety.dart:133` — 均无需修改（`now` 可选参数默认 `DateTime.now()`）
- **验证**: `flutter analyze` 通过（3 个修改文件）
