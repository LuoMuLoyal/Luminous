# Migration Log — 2026-08-16

## fix(security): 安全提升异常可见化并拒绝非法过期时间兜底

- `security_elevation.dart` `verify()`:裸 `on Object` 吞错拆分为三层——可预期失败(DioException:网络/HTTP 错误及业务码非 0 经 EnvelopeInterceptor 转换;LucentApiException:拦截器未生效的调用路径)直接返回 false 不产生噪音日志;意外异常(TypeError、空响应、解析错误等)用 `appTalker.error` 记录错误与堆栈后返回 false,消除生产"验证莫名失败"调试黑洞。
- 响应解包改用 `requireData` + 显式 `ensureEnvelopeSuccess` 校验业务码,替换裸 `response.data!`:拦截器未生效时,失败响应不再被误当作成功并签发提升令牌。
- `expiresAt` 解析失败不再回退"当前时间 + 15 分钟":记录警告日志并拒绝设置提升令牌、返回 false,杜绝服务端异常或被篡改的响应人为延长安全提升状态。
- 新增 `test/core/providers/security_elevation_test.dart`:覆盖成功路径、非法 expiresAt 拒绝、DioException 降级、业务码非 0、意外异常记录日志等用例。
- 验证:`flutter analyze` 无告警;security_elevation 与 user_settings_controller 相关测试全部通过。
