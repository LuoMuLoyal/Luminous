## fix(security): 安全提升异常可见化并拒绝非法过期时间兜底

- `security_elevation.dart` `verify()`:裸 `on Object` 吞错拆分为三层——可预期失败(DioException:网络/HTTP 错误及业务码非 0 经 EnvelopeInterceptor 转换;LucentApiException:拦截器未生效的调用路径)直接返回 false 不产生噪音日志;意外异常(TypeError、空响应、解析错误等)用 `appTalker.error` 记录错误与堆栈后返回 false,消除生产"验证莫名失败"调试黑洞。

## fix(auth): 刷新失败区分认证失效与临时故障,保留会话避免误登出

- 测试:改写"401 非 tokenExpired 不清会话"用例为新语义,新增网络错误/5xx 刷新失败保留会话、不可刷新业务码直接清会话等用例。

## F-5 P1 依从性口径统一（前端 mapper 层，ObservedMetric 稀疏语义）

用药管理改造计划 3.2 节 F-5 的 P1 部分（纯前端，只改 `lib/features/medicine/` 与相关文档/测试；
不提交 git，由主控审查后提交）。

### 统一口径

- 分母 = **已到期槽位**（已确认 taken / 已跳过 skipped / 已超时未确认 overdue 三类），分子 = **已确认槽位（taken）**。
- 未确认 ≠ 漏服；漏服语义由 `overdueUnconfirmed` 派生、不落库为 `missed`；未到期槽位不计入分母；
  无覆盖/无到期槽位显示 `--`。

### 决策（主控拍板，直接执行）

1. 分子 = taken only（skipped 计入分母不计分子）。
2. 「已到期」= 当前墙钟 >= 槽位 HH:mm（`now.hour > scheduledHour || (now.hour == scheduledHour && now.minute >= scheduledMinute)`）；**不做** 30 分钟宽限（宽限只影响后端漏服分类，不影响「到期」分母）。
3. 时区沿用 `package:clock` 的 `clock.now()`（设备本地墙钟，与既有 `dateStr`、`reminder.matchesDate(today)` 一致）；profile timezone 对齐留给 F-5 P2 后端统计对象。
4. 建模：`MedicineDoseSlot` 增加 `@Default(false) bool isOverdue`（不新增 MedicineDoseStatus 枚举值）；status 仍为 pending 的槽若已过时刻则 `isOverdue: true`；打卡按钮逻辑不变（overdue 槽仍可补卡，status 仍是 pending）。
5. `metricDosesToday` 是 F-17 已标注死字段：继续填「今日计划槽位总数」（各 item slots.length 之和），删除「无槽位记 1」的 hack（旧 `_plannedDoseCount` 的 `return 1` 分支）。
6. `metricAdherence`：分母 = 已到期槽位数（taken+skipped+overdue）、分子 = taken；分母 0 → `'--'`。
7. `metricNextDose`（死字段）与「下一剂」展示：下一**未到期** pending 槽；无未到期槽 → null/'--' 走既有空态。
