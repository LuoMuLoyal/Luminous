## Review Experience — Task 4 Flutter Review 领域层

- 新增 Review 领域实体（`lib/features/report/domain/entities/review.dart`）：以健康事件为主单位的 `EventReview` 读模型，包含事件头部、四段 sections、三数据源 coverage、source timestamps 与 available actions。section state / reasonCode / coverage / source 按契约原文保留：reasonCode 原样透传，未知枚举值映射为显式 `unknown` 成员，不折叠成空列表或 0。
- 新增 `ReviewRepository` 接口（current / history / detail）与 `LucentReviewRepository` 实现：current 优先 active 事件否则最近 ended，无事件时空信封映射为 null；history 支持 status/cursor/limit 分页；detail 按事件 ID 取完整回顾，事件不存在时由后端 404 抛错。
- 新增 `reviewCurrent / reviewHistory / reviewDetail` provider：current 为主（keepAlive + dailyRecords/doseLogs 变化自动刷新），`reviewLastCurrentProvider` 保留最后一次成功数据；history keepAlive 缓存第一页；detail 为 autoDispose family，切换事件 ID 丢弃旧结果。失败重试由 `ref.invalidate` 驱动。
- `scripts/bootstrap_generated_sources.dart` 改为 TodayAnalysis 与 Reports 两次过滤生成（openapi-generator-cli 7.x 的 `apis` 只接受单值），generated client 新增 14 个 event review DTO、`reports_api.dart` 的 3 个 review 方法及 barrel/deserialize 同步。
