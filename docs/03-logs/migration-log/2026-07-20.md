# Migration Log - 2026-07-20

## Luminous — UI/UX P0 修复：死路由、文案错误、Toast 键值复用、测试修复

- **来源**：`plans/2026-07-20-uiux-optimization-verification.md`（基于 `plans/2026-07-18-uiux-per-page-optimization.md`）。
- **验证方式**：`flutter analyze` 零问题，`flutter test` 2756 个测试全部通过。

### P0 修复 7 项

1. **死路由 `/medicine/reminders`**：`router.dart` 移除 `AppRoutes.medicineReminders` 常量（该路由无对应页面，跳转后 404）。用药页铃铛按钮改为跳转 `AppRoutes.notifications`（通知列表页）。Today 快捷操作"用药提醒"从 `medicineReminders` 改为 `medicineRemindersNew`（新建提醒页）+ `usePush: true`。
2. **`_MedicineSafeGuardPill` 窄屏断言**：窄屏下 `FButton` 的 `child: null` 触发 Forui 断言。修复：根据 `isNarrow` 条件切换 `FButton.icon`（仅图标）和 `FButton`（图标+文字），消除 `child: null`。
3. **提醒切换失败 Toast 复用 `settingsSyncFailed`**：`reminder_detail.dart` 的启停切换失败 Toast 从 `l10n.settingsSyncFailed` 改为专用 `l10n.medicineReminderToggleFailedToast`（"切换提醒状态失败"）。
4. **扫码识别中文案复用 `scanRecognitionFailedToast`**：`barcode_scanner.dart` 的识别中状态从 `l10n.scanRecognitionFailedToast`（"识别失败"）改为 `l10n.scanRecognizingHint`（"识别中…"），不再在识别过程中显示失败文案。
5. **帮助页空态/错误态 description 重复 title**：`help.dart` 的空态和错误态 `AppStateMessageView` 传入 `description` 与 `title` 完全相同。修复：移除 `description` 参数（`AppStateMessageView` 的 `description` 现已支持可选）。
6. **高级设置页残余分组标题**：`advanced.dart` 移除"恢复默认设置"的 `SettingsSectionLabel`（对应的 `FTileGroup` 已在前一次修改中删除，标题残留）。
7. **`AppStateMessageView.description` 改为可选**：`state_message.dart` 的 `description` 参数从 `required String` 改为 `String?`，`null` 时不渲染描述行。帮助页等仅需标题+图标的场景不再需要传入重复文案。

### 新增 l10n 键

- `medicineReminderToggleFailedToast`（"切换提醒状态失败" / "Failed to toggle reminder status."，zh + en）。
- `scanRecognizingHint`（"识别中…" / "Recognizing…"，zh + en）。

### 测试修复 3 项

1. **`reminder_form_body_test.dart` — `pumpAndSettle` 超时**：`isSaving: true` 时 `FCircularProgress` 是无限动画，`pumpAndSettle` 永远无法完成。修复：为 `_pumpForm` 增加 `settle` 参数，`isSaving` 测试中用 `pump(Duration(milliseconds: 100))` 替代 `pumpAndSettle()`。
2. **`dashboard_test.dart` — 时相关断言**：`TodayDashboard.signedOut()` 使用 `DateTime.now().hour` 动态计算时段，测试硬编码期望 `morning` 在下午运行时失败。修复：改为用 `todayDayMomentFromHour(DateTime.now().hour)` 动态计算期望值。
3. **其他测试修复**（前序会话完成）：`medicine_search_notifier_test.dart`（防抖等待）、`subpages_test.dart`（BOM 字符）、`providers_test.dart`（改用 repository 测试避免超时）、`ocr_entry_dialog_test.dart`、`reminder_pages_test.dart` 等。
