# Migration Log — 2026-07-22

## 审查报告问题修复

### main.dart — Zone mismatch 修复

- 之前的改动将 `WidgetsFlutterBinding.ensureInitialized()` 移到 `runZonedGuarded` 外部，
  导致 Flutter 抛出 "Zone mismatch" 异常：binding 初始化的 zone 与 `runApp` 的 zone 不一致。
- 弃用 `runZonedGuarded`，改用 `PlatformDispatcher.instance.onError` 捕获异步未捕获错误。
  这是 Flutter 3.x+ 推荐的现代模式，同时满足：
  - `ensureInitialized` 在 root zone（同步异常正常崩溃，不被静默吞咽）
  - `runApp` 也在 root zone（无 zone mismatch）
  - 异步未捕获错误仍通过 `PlatformDispatcher.instance.onError` 上报到 Sentry
- 移除了 `dart:async` import（`runZonedGuarded` 不再使用）。

### luminous-cd.yml — CI/CD secrets 校验步骤

- 新增 "Validate required secrets" 步骤，在 Flutter 构建前检查 `LUCENT_BASE_URL` 和 `SENTRY_DSN` 两个 GitHub secrets 是否已配置，未配置时 `exit(1` 中断流水线，防止空字符串注入 `--dart-define`。

### dialog_test.dart — 测试 group 名称同步

- `group('AppDialogShell', ...)` 更新为 `group('DialogShell', ...)`，与类名一致。

### showAppDialog 增加 barrierDismissible 参数

- `lib/core/widgets/common/dialog_shell.dart`：`showAppDialog` 新增 `barrierDismissible` 参数（默认 `true`），透传至 `showFDialog`。
- `lib/features/scan/presentation/pages/box_scan.dart`：两处 `showFDialog` 直接调用改为 `showAppDialog`（结果对话框 + 处理遮罩），统一 dialog 封装入口。
- `lib/features/scan/presentation/widgets/dialogs/recognize_dialog.dart`：移除 `FDialog` 包装层，改为直接返回 `Column` 内容；移除 `animation` 参数（由 `DialogShell` 统一处理）；`style.titleTextStyle` 改为 `context.theme.dialogStyle.titleTextStyle`。
