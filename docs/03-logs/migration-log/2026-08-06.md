# 2026-08-06 全仓库代码审查修复

来源：`plans/Luminous-review-2026-08-06.md`（7 🔴 + 9 🟡，经代码验证后实际修复 6 项严重 + 3 项警告，其余已修复或误报）

## 🔴 严重

### 1. `response.data!` 强制解包 — 运行时崩溃风险

- `lib/features/auth/data/datasources/auth.dart`
  - 新增 `_requireBody<T>(T? body)` 私有方法，对 null 响应体抛出 `StateError` 而非 `NullPointerException`。
  - 全文件 20 处 `response.data!.data` 替换为 `_requireBody(response.data).data`。

### 2. Enum 解析无 `orElse` — `StateError` 崩溃风险

- `lib/features/record/data/datasources/record.dart`
  - `_parseKind` 添加 `orElse: () => DailyRecordKind.note` 回退。
- `lib/features/medicine/data/datasources/dose_log_remote.dart`
  - `_parseStatus` 添加 `orElse: () => DoseLogStatus.planned` 回退。
- 注：审查列出的 10 处中，8 处已有 `orElse`，仅上述 2 处实际缺失。

### 3. `selectedResult` getter 使用 `firstWhere` 无 `orElse`

- `lib/features/search/domain/entities/entities.dart`
  - `selectedResult` 返回类型从 `MedicineSearchResult` 改为 `MedicineSearchResult?`。
  - 使用 `firstWhereOrNull` 替代 `firstWhere`，避免 `StateError`。
- `test/search/domain/entities/entities_test.dart`
  - 测试用例更新：匹配时使用 `!` 断言，不匹配时期望返回 `null` 而非抛出 `StateError`。

### 4. `catch (_)` 静默吞掉关键错误 — 10 处

以下文件的 `catch (_)` 改为 `catch (e, st)` 或 `catch (e)`，并通过 `appTalker` 记录错误详情：

- `lib/features/record/presentation/quick_entry/symptom_flow.dart` — `recordBatch` 批量记录失败日志
- `lib/features/record/presentation/services/quick_entry_executor.dart` — 水量记录失败 + 撤销失败日志
- `lib/features/record/presentation/widgets/dialogs/meal_confirmation.dart` — 饮食确认保存失败日志
