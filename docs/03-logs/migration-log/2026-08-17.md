Lucent Task 7 将 Today Analysis 改为服务端事件驱动的物化读模型：GET 只读取 `empty/pending/ready/stale/failed` 状态，写入相关事实后由服务端限次生成。Luminous 需要把物化状态映射到 Today domain/UI，并补齐 `ai_today_summary` 推送路由。

### 实体层

- `lib/features/today/domain/entities/ai_analysis.dart`：
  - 新增 `TodayAiAnalysisMaterializationStatus` 枚举：`empty`、`pending`、`ready`、`stale`、`failed`。
  - `TodayAiAnalysis` 新增 `materializationStatus`（默认 `ready`）与 `aiGenerated`（默认 `true`）字段；当前实体只有 `TodayAiAnalysisMaterializationStatus`，不存在独立的 `TodayAiAnalysisStatus`。
  - 新增 `TodayAiAnalysisCardState` 数据类，聚合 provider 输出状态：`analysis`、`status`、`aiGenerated`、`isEmpty`、`isDisabled`、`showRefresh`、`showMaterializationNotice`、`materializationNotice`、`lastUpdated`。

### 数据层

- `lib/features/today/data/datasources/ai_remote.dart`：
  - 新增 `read(DateTime date)`：调用 `GET /today/analysis`，把 `TodayAnalysisReadDataDto` 映射到 domain。
  - 新增 `refresh(DateTime date)`：由于生成的 OpenAPI union DTO `TodayAnalysisRefreshResponseDtoData` 把 oneOf 分支合并为所有字段 required 的扁平对象，无法安全地直接用生成方法反序列化。改为走 raw Dio 获取响应体，再按 `status` / `analysis` 字段手工归一化为 `TodayAnalysisReadDataDto`，最后映射到 domain。
  - `generateStream` 适配新的 generate API envelope：`data` 字段类型已变为 `TodayAnalysisAsyncResultDataDtoResult`，测试与仓库层同步更新。

- `lib/features/today/data/repositories/lucent_ai.dart`：
  - 新增 `read(DateTime)` / `refresh(DateTime)`，统一映射到 `TodayAiAnalysis`。
  - `refresh()` 语义为“请求服务端重新物化并返回当前状态”，不直接触发完整生成流。

### Provider 层

- `lib/features/today/presentation/providers/ai_analysis.dart` 重写为 `AsyncNotifier<TodayAiAnalysisCardState>`：
  - `build()` 在认证通过且用户开启 AI 摘要后读取 persisted analysis（`read()`）。
  - 把 5 种 materialization 状态映射为 UI 状态：`empty` 显示真实空态并允许刷新；`ready` 展示分析内容；`pending/stale/failed` 保留上一次 analysis 并在 notice 区提示用户。
  - 监听 `DataChangeBus` 相关 topic（`dailyRecords`、`doseLogs`、`medicineReminders`、`healthContext`、`currentMedicines`、`userSettings`、`healthEvents`）并以 300ms debounce 重新 `read()`，不调用生成接口。
  - 应用 `resume` 时 Diff 刷新：比较前后 `sourceVersion`，变化时才触发状态更新。
  - 暴露 `refresh()` action 供 UI 调用。

### UI 层

- `lib/features/today/presentation/widgets/sections/summary.dart`：
  - 按 `AsyncValue<TodayAiAnalysisCardState>` 重构，区分 `loading/error/data`。
  - data 状态根据 `isEmpty`、`isDisabled`、`showMaterializationNotice`、`showRefresh` 渲染不同视图。
  - 新增物化提示条（pending/stale/failed）与刷新按钮。
  - 摘要标签改为 rule-based：根据 `aiGenerated` 与内容状态展示「AI 生成摘要 / 待生成 / 生成失败」等文案。

### 关键决策
