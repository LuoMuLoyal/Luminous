## F-2 反馈提交改局部静默刷新

### 背景

Today 主建议卡底部反馈按钮点击后，`todaySuggestionProvider` 会把整个 `state` 切为 loading，导致主卡闪烁骨架屏、旧内容消失。

### 改动

- `lib/features/today/presentation/providers/suggestion.dart`：
  - `submitFeedback` 不再设置 `AsyncValue.loading()`，提交期间保持当前 bundle 可见。
  - 先调用 `ds.submitFeedback(...)`；若 feedback 为 `suppress`，将 `suggestionId` 加入 `_dismissedIds`。
  - 成功后后台静默调用 `_fetch()`，用 `AsyncData(bundle)` 替换 state。
  - 若 `_fetch()` 失败，仅记录 warning，不替换 state、不向 UI 抛异常，避免已显示的「已提交」状态被撤销。
  - 若 `submitFeedback` 本身失败，原样抛出异常，由 `SuggestionFeedbackRow` catch 并显示失败 toast，不标记 `_submittedFeedback`。
  - 更新类注释，说明 `submitFeedback` 与 `dismiss`/`refresh` 的 loading 语义差异。

- `test/today/presentation/providers/suggestion_provider_test.dart`：
  - 新增/更新 4 个用例覆盖：提交期间 `state.isLoading` 为 false 且保留旧 bundle；成功后静默拉取新 bundle 并替换；刷新失败保留旧 bundle；提交失败抛出异常且保留旧 bundle。

- `docs/00-current/Active_UI_Today.md`：
  - 更新「主建议卡」节反馈区描述，说明提交期间保留旧卡内容、按钮置 loading、成功后静默刷新。

### 验证

- `flutter analyze` 零告警。
