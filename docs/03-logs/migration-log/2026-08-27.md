## fix(medicine): 药品详情页 CheckedFromJsonException 修复

药品详情页（`GET /api/v1/medicines/:id?source=cn`）一直显示骨架屏。前端日志显示 `CheckedFromJsonException: Could not create MedicineDetailResponseDtoDetail. Required keys are missing: groups, categories, atcCodes, synonyms, foodInteractions`。

后端 `DrugbankMedicineDetailDto` 中这 5 个 DrugBank 列表字段使用 `@ApiProperty`（非 optional），OpenAPI spec 标记为 required。生成的 Dart DTO 用 `required: true` + `checked: true`，CN 药品详情 JSON 不含这些字段时 `fromJson` 抛异常。

### 改动

- `generated/lucent_api/`：重新生成 Flutter 客户端（后端 DTO 改为 `@ApiPropertyOptional(nullable: true)` 后，生成代码中这 5 个字段变为 `required: false` + `List<String>?`）。
- `lib/features/medicine/data/mappers/medicine_detail.dart`：`detail.groups` 等改为 `detail.groups ?? const []` 处理 null。
