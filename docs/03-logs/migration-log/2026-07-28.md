### 🔴 严重：数据源强制解包修复

#### `risk_check_remote.dart` — `response.data!.data` 强制解包

- `fetchRecords()` 和 `runCheck()` 中 `response.data!.data` 在 `response.data` 为 null 时触发 `NullThrownError` 崩溃。
- 改为检查 `response.data` 是否为 null，为 null 时抛出 `LucentApiException(emptyResponse)`。
- DTO 内部 `.data` 字段为 non-nullable（`required: true`），只需检查外层 `response.data`。

#### `safety_tips_remote.dart` — `response.data!.data` 强制解包

- `fetchTips()` 中同样问题，同上模式修复。

#### `dose_log_remote.dart` — `_coerce` 返回 null 后 `body!['data']` 强制解包

- 四个方法（`fetchForDate`、`create`、`update`、`mark`）均先调用私有 `_coerce(response.data)`（返回 nullable），随后 `body!['data']` 强制解包。
- 删除私有 `_coerce` 方法，改用项目已有的 `requireBody(response)`（来自 `map_utils.dart`）。
- 新增 `_requireData` 和 `_requireItemMap` 私有方法，统一使用 `coerceToStringMap` + `LucentApiException` 模式。

## 用药提醒编辑页 Bug 修复

### 频率选项点击无反应

- **文件**：`lib/features/medicine/presentation/widgets/reminder/form_fields.dart`、`lib/features/report/presentation/widgets/sections/ai_summary.dart`
- **根因**：`FSelectGroup` + `FMultiValueControl.lifted` 管理单选状态时，底层 `_ProxyNotifier.update()` 在点击新选项时将新值 **添加** 到集合中而不移除旧值，导致 `onChange` 回调收到 `{旧值, 新值}`。原代码 `value.first` / `selection.first` 按 Set 迭代顺序返回旧值，状态不变，UI 不刷新。
- **修复**：两处均改为 `value.where((v) => v != currentValue).firstOrNull` 过滤出新增的值。

### 开始/结束日期行间隙与边框消失

- **文件**：`lib/features/medicine/presentation/widgets/reminder/rows.dart`
- **根因**：`ValueActionRow` 使用 `FTile`，其 `FTileStyle.contentDecoration` 自带 `ShapeDecoration`（含 `color: colors.card` 背景和 `BorderSide` 边框）。这导致两个问题：
  1. 两个 `FTile` 用 `AppDivider` 分隔时，各自边框在分隔线上下产生多余间隙。
  2. `FTile` 的背景色会覆盖 `FCard` 的边框（`FCard` 的 `clipBehavior` 默认为 `Clip.none`，不裁剪子组件），导致边框消失。
  3. `FTile` 的 `borderRadius.md` 与 `FCard` 的 `borderRadius.lg` 不一致，底部圆角不统一。
- **修复**：完全弃用 `FTile`，改用 `FTappable` + `Padding` + `Row`（与 `SwitchRow` 等其他行一致的模式）。`FTappable` 不带 `ShapeDecoration`，不会覆盖 `FCard` 的边框和背景。`FCard` 的 `borderRadius.lg` 成为唯一的圆角边框来源，无论选择每日、每周还是自定义，底部都是统一的圆角。

## 用药主页 UI/UX 优化

### 药箱截断问题修复

- **文件**：`lib/features/medicine/presentation/widgets/sections/mobile_drugbox.dart`
- **根因**：`_DrugBoxContent` 左侧有 `_DrugBoxCountSummary`（固定宽 `Spacing.level9`），用大字号重复显示药品总数。该数字已在 `_DrugBoxHeader` 中展示，属冗余。窄屏下 `SkeletonText` 设 `widthFactor: 0.72` + `maxLines: 1` 导致文本被截断为 "1..."。
- **修复**：删除 `_DrugBoxCountSummary` 组件及竖分隔线，`_DrugBoxContent` 改为直接展示药品列表的 `Column`。`_DrugBoxHeader` 的图标 + 总数 + 管理按钮已足够表达药箱概览信息。

### 今日计划重复操作按钮消除

- **文件**：`lib/features/medicine/presentation/widgets/sections/mobile_drugbox.dart`、`mobile_records.dart`
- **根因**：`_DrugBoxReminderStrip`（今日计划卡片顶部的"下次用药"摘要区）内含 Taken/Skipped 按钮，而下方每个 `_TodayPlanRow` 行也有同样的按钮。当"下次用药"对应的药品出现在列表中时，同一药品在同一张卡片内出现两组操作按钮，用户困惑。
- **修复**：`_DrugBoxReminderStrip` 移除 `onMarkDose` 参数及 Taken/Skipped 按钮区域，只保留"下次用药时间"和"依从率"两个信息摘要。操作按钮仅保留在 `_TodayPlanRow` 行内，用户在列表中找到对应药品直接操作。
