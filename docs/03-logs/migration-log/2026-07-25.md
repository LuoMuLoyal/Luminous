## 设计系统 token 升级：Motion / IconSize / Elevation / Gradient

新增 4 个 design token 文件，替换全部硬编码 `Curves.*`、`Icon(size: N)`、`BoxShadow` 和内联 `LinearGradient`。

### 新增 token 文件

| 文件 | Token | 说明 |
|---|---|---|
| `lib/core/design/motion.dart` | `MotionTokens` | 4 个 curve token（`entrance`/`exit`/`standard`/`snappy`）；`DurationTokens` 从 `durations.dart` 迁移至此 |
| `lib/core/design/icon_size.dart` | `IconSizeTokens` | 5 级 icon size（`level1`=12, `level2`=16, `level3`=20, `level4`=24, `level5`=32） |
| `lib/core/design/elevation.dart` | `ElevationTokens` | `raised(FColors)` / `glow(Color)` / `shadowColor(FColors)`，暗色模式 alpha 自动补偿 |
| `lib/core/design/gradient.dart` | `GradientTokens` | `semanticFill(SemanticColorPalette)` / `tintFade(Color, Color)` 两个命名渐变模式 |

`durations.dart` 已删除，`design.dart` barrel 更新导出。

### 替换汇总

| 类别 | 替换数 | 映射 |
|---|---|---|
| `Curves.*` → `MotionTokens.*` | 10 处 | `easeOutCubic`→`entrance`, `easeOut`→`snappy`, `easeInOut`→`standard` |
| `Icon(size: N)` → `IconSizeTokens.level*` | 30+ 处 | 12→level1, 14/16→level2, 18/20→level3, 22/24→level4, 32/36→level5 |
| 内联 `BoxShadow` → `ElevationTokens.*` | 2 处 | `timeline.dart`→`raised`, `voice_entry_dialog.dart`→`glow` |
| `foruiMaterialTheme` shadowColor → `ElevationTokens.shadowColor` | 1 处 | `theme.dart` |
| `LinearGradient` → 纯色/token | 3 处 | `hero.dart`×2→`SemanticColor.primary.subtle`（纯色），`components.dart`→`GradientTokens.semanticFill`（`filled` 参数替代旧 `gradient` 参数） |

## 桌面端窗口管理修复

### 窗口控制按钮位置

- **问题**：min/max/close 按钮在左侧导航栏的右上角（受 sidebar 宽度约束），而非应用程序窗口的右上角。
- **修复**：新增 `lib/core/widgets/common/desktop_window_chrome.dart`（`DesktopWindowChrome`），在 `bootstrap.dart` 的 app builder 中以 `Column` 布局置于应用顶部，横跨整个窗口宽度。按钮在 `Row` 末尾，定位在窗口右上角。
- `page.dart` 的 `_WindowTitleBar` 简化为 `StatelessWidget`，仅保留 `DragToMoveArea`（侧边栏头部拖拽区）和 macOS traffic-light padding。`_WindowControlButtons` / `_WindowButton` 类移至 `desktop_window_chrome.dart`。

### 窗口拖拽修复

- **问题**：`DragToMoveArea` 仅覆盖侧边栏头部，窗口其他区域无法拖拽。
- **修复**：`DesktopWindowChrome` 包含一个全宽 `DragToMoveArea`（32px 高），位于应用顶部。侧边栏头部的 `DragToMoveArea` 保留作为额外拖拽区。

### 侧边栏展开/收窄动画

- **问题**：`AnimatedContainer` 的 `width: collapsed ? 64 : null` 无法在具体数值与 `null` 之间插值，宽度瞬间跳变。
- **修复**：替换为 `AnimatedSize`（`duration: DurationTokens.widgetStandard` = 300ms，`curve: MotionTokens.standard` = easeInOut，`alignment: centerLeft`），内嵌 `SizedBox` 设置宽度。`AnimatedSize` 监听子组件实际渲染尺寸并平滑过渡，内容被 clip 住，标签逐渐揭开/收起。
