# 2026-07-25 集成测试修复

## 变更摘要

修复 ForUI 组件迁移后集成测试的查找器和异步状态泄露问题。

## 改动文件

### `integration_test/support/e2e_test_helpers.dart`

- 在 `pumpOfflineApp` 中覆盖 `lucentDioClientProvider`，在 `ref.onDispose` 时 `interceptors.clear()` 而非 `client.dispose()`，避免 `LiveTestWidgetsFlutterBinding` 的 `_pendingFrame` 断言失败。
- 移除了之前引入的 `_OfflineTestAdapter` 和 `RetryInterceptor` 移除逻辑——这些在多文件连续运行时反而导致更多帧泄露。

### `integration_test/today/today_signed_in_e2e_test.dart`

- `BackButton` → `AppBackButton` 查找器修复。
- 对不在视口内的元素添加 `tester.drag` 滚动逻辑。

### `integration_test/record/record_create_e2e_test.dart`

- `AppBackButton` 查找改为 `find.descendant(of: find.byType(AppBackButton), matching: find.byType(FButton))`。
- save 按钮添加 `ensureVisible` + `warnIfMissed: false`。
- `vital kind` 测试改为 `water kind`，值从 `120/80` 改为 `250`（water 验证要求正数）。

## 已知限制

`medicine_edit_e2e_test.dart` 和 `record_create_e2e_test.dart` 在与其他测试文件连续运行时仍可能出现 `_pendingFrame` 断言错误（Dio TCP 连接定时器泄露）。这两个文件需单独运行：

```bash
flutter test -d emulator-5554 integration_test/record/record_create_e2e_test.dart
flutter test -d emulator-5554 integration_test/mine/medicine_edit_e2e_test.dart
```

三个已有测试文件（`today_e2e`、`today_signed_in`、`route_guard`）可连续运行，23 个测试全部通过。
