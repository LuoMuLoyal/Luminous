# 2026-07-31 代码审查修复

## health_data — 血压配对逻辑修复

- `lib/features/health_data/data/mappers/health_record_mapper.dart`
  - 将血压 systolic/diastolic 配对逻辑从 Repository 移至 Mapper，利用 `HealthDataType.BLOOD_PRESSURE_SYSTOLIC` / `BLOOD_PRESSURE_DIASTOLIC` 精确区分收缩压与舒张压，修复相同时间戳下 sort 顺序不确定导致数值互换的问题。
  - 新增 `_BloodPressureDataPoint` 临时持有类，保留原始类型信息。
  - 更新类和方法文档注释以反映新增的 BP 配对职责。
- `lib/features/health_data/data/repositories/health_sync.dart`
  - 移除 `_pairBloodPressure` 方法（配对逻辑已移至 Mapper）。
  - `fetchMetrics` 简化为直接返回 `mapper.mapToMetrics(points)`。
  - `_buildDedupFingerprints` 中 `pageSize` 从 200 提升至 2000，避免高频健康数据（如心率每秒采样）场景下去重指纹集合不完整。
