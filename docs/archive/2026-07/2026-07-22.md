# Migration Log — 2026-07-22

## 审查报告问题修复

### main.dart — Zone mismatch 修复

- 之前的改动将 `WidgetsFlutterBinding.ensureInitialized()` 移到 `runZonedGuarded` 外部，
  导致 Flutter 抛出 "Zone mismatch" 异常：binding 初始化的 zone 与 `runApp` 的 zone 不一致。
- 弃用 `runZonedGuarded`，改用 `PlatformDispatcher.instance.onError` 捕获异步未捕获错误。
  这是 Flutter 3.x+ 推荐的现代模式，同时满足：
  - `ensureInitialized` 在 root zone（同步异常正常崩溃，不被静默吞咽）
  - `runApp` 也在 root zone（无 zone mismatch）
  - 异步未捕获错误仍通过 `PlatformDispatcher.instance.onError` 上报到 Sentry
- 移除了 `dart:async` import（`runZonedGuarded` 不再使用）。

### luminous-cd.yml — CI/CD secrets 校验步骤

- 新增 "Validate required secrets" 步骤，在 Flutter 构建前检查 `LUCENT_BASE_URL` 和 `SENTRY_DSN` 两个 GitHub secrets 是否已配置，未配置时 `exit(1` 中断流水线，防止空字符串注入 `--dart-define`。

### Android 模拟器网络连接修复

- **问题**：在 Android 模拟器上点击发送验证码时报 `DioException [connection error]`，后端已正常运行。
- **根因 1**：`127.0.0.1` 在 Android 模拟器上指向模拟器自身的 loopback，而非宿主机。需要使用 `10.0.2.2` 才能访问宿主机的 localhost。
- **根因 2**：Android 9+（API 28+）默认禁止明文 HTTP 流量，而 `debug/AndroidManifest.xml` 未声明 `android:usesCleartextTraffic="true"`。
- **修复 1**：`android/app/src/debug/AndroidManifest.xml` 新增 `<application android:usesCleartextTraffic="true"/>`，允许 debug 构建下的明文 HTTP（release 不受影响，使用 HTTPS）。
- **修复 2**：`lib/core/network/base_url.dart` 的 debug 回退 URL 改为平台感知——Android 返回 `http://10.0.2.2:3000`，其他平台保持 `http://127.0.0.1:3000`。
- **修复 3**：`lib/core/config/developer_settings_controller.dart` 的 `resolvedBaseUrl` getter 对 `ApiEndpoint.local` 做平台适配——Android 返回 `10.0.2.2`，其他平台返回 `127.0.0.1`。

### Record 页面分页参数验证失败修复

- **问题**：登录后跳转 record 页面时，后端返回 400 验证错误：`page must be an integer number; pageSize must be an integer number` 等全部分页验证失败。
- **根因**：后端 `QueryDailyRecordDto` 的 `page`/`pageSize` 缺少 `@Type(() => Number)` 装饰器，`class-transformer` 未将查询字符串转换为 `Number` 类型，导致 `@IsInt()` / `@Min()` / `@Max()` 验证全部失败。
- **修复**：后端 DTO 添加 `@Type(() => Number)` 装饰器（`Lucent/src/modules/daily-records/dto/query-record.dto.ts`），重新导出 OpenAPI 并重新生成 Dart 客户端。

### Today 页面 TickerMode NoSuchMethodError 修复

- **问题**：登录后切换 tab 时，Today 页面报 `Class '_TodaySummarySectionState' has no instance getter '_tickerModeNotifier'`，程序卡死。
- **根因**：`_MobileTodayDashboard` 和 `_DesktopTodayDashboard` 的 `ListView` 中有条件项 `if (isPreview) SignInHintBanner(...)`，当 `isPreview` 在登录后变化时，列表项索引全部移位，导致 `SingleTickerProviderStateMixin` 状态（`_SuggestionPrimaryCardState`、`Shimmer._ShimmerState`、`AnimatedSwitcher` 等）被 dispose/recreate。在这个重建窗口期，`IndexedStack` 的 `TickerMode` 通知被分发到已被替换但尚未清理的监听器上，触发 `NoSuchMethodError`。
- **修复**：将 `ListView.separated` / `ListView` 改为 `CustomScrollView` + `SliverList`，并将条件 `SignInHintBanner` 改为 `if/else` 始终占位（`SignInHintBanner` 或 `SizedBox.shrink`），使列表项数量和索引在 `isPreview` 变化时保持不变。

### 健康档案可空枚举反序列化失败修复

- **问题**：登录后获取健康档案时，`UserHealthProfileDto.sexAtBirth` 反序列化报 `CheckedFromJsonException`，程序卡在 Mine 页面。
- **根因**：`openapi_retrofit_generator` 对 `nullable: true` + `allOf` + `$ref` 模式的枚举字段生成非空类型。后端返回 `null` 时 `v as String` 崩溃。
- **修复**：后端 `response.dto.ts` 和 `update-profile.dto.ts` 中枚举字段的 `@ApiPropertyOptional` 移除 `nullable: true`（该标志反而导致生成器生成非空类型）。重新运行 `openapi_retrofit_generator` + `build_runner` 重新生成客户端。`lib/features/health_context/data/mappers/mapper.dart` 三处 `.name` 改为 `?.name`。

### GitHub Pages 只显示图标修复（Sentry DSN 无效导致初始化崩溃）

- **问题**：`https://luomuloyal.github.io/Luminous/` 部署后只显示 splash 图标，Flutter 应用未渲染。
- **根因**：CD 工作流强制要求 `SENTRY_DSN` 非空，但没有真实 Sentry 项目时用户只能填占位符 `https://api.lumos.example.com`。该值非有效 Sentry DSN（缺公钥 `@` 和项目 ID 路径），Sentry SDK 解析时抛出 `Invalid argument(s): Project ID not found in the URI path of the DSN URI` 异常。`_initSentry()` 在 `runApp()` 之前 `await`，异常导致应用初始化中断。
- **修复 1**（`.github/workflows/luminous-cd.yml`）：`SENTRY_DSN` 改为**可选**——未设置时输出 warning 并继续构建（`--dart-define=SENTRY_DSN=` 传入空字符串，应用跳过 Sentry）；已设置但格式无效时才 `exit(1)` 拦截，并提示"要禁用 Sentry 请删除该 secret 而非填占位符"。
- **修复 2**（`lib/main.dart`）：`_initSentry()` 增加 `try-catch` 包裹 `SentryFlutter.init()`，作为兜底安全网——即使 DSN 非空但无效，应用也不会崩溃，Sentry 降级为 no-op。

### Web 端移动浏览器只显示导航栏修复（渲染器自动选择）

- **问题**：GitHub Pages 部署后，电脑浏览器正常渲染，但手机浏览器只显示底部导航栏，页面主体空白。
- **根因**：Flutter 3.44.0 默认使用 CanvasKit 渲染器（WebAssembly + WebGL），在移动浏览器上加载大型 WASM 文件可能失败，导致渲染不完整。旧的 `html` 渲染器在 Flutter 3.30+ 已被移除。
- **修复**：
  1. `web/flutter_bootstrap.js`：检测移动设备 UA，桌面强制 `canvaskit`，移动端不指定渲染器让 Flutter 自动选择（优先 `skwasm` — 基于 WasmGC 的轻量渲染器，不支持时回退 `canvaskit`）。
  2. `.github/workflows/luminous-cd.yml`：构建命令新增 `--wasm` 标志，使构建产物同时包含 `skwasm`（dart2wasm）和 `canvaskit`（dart2js）两种渲染器，供运行时选择。
- **注意**：Flutter 3.44.0 的 `WebRenderer` 类型为 `"canvaskit" | "skwasm"`，`html` 渲染器已移除。`skwasm` 是 `html` 的现代替代品，更轻量且支持 WasmGC。

#### Luminous 前端测试修复

**1. URL 平台感知测试（4 个失败）**

- **文件**：`test/core/network/base_url_test.dart`、`test/core/config/developer_settings_controller_test.dart`
- **根因**：`base_url.dart` 和 `developer_settings_controller.dart` 使用 `defaultTargetPlatform == TargetPlatform.android` 返回 `10.0.2.2`（Android 模拟器专用），但 Flutter 测试环境默认 `defaultTargetPlatform` 为 `android`，导致测试期望 `127.0.0.1` 却得到 `10.0.2.2`。
- **修复**：测试 `setUp` 中设置 `debugDefaultTargetPlatformOverride = TargetPlatform.windows`，`tearDown` 恢复原值。

**2. page_test.dart 滚动容器查找（5 个失败）**

- **文件**：`test/today/page_test.dart`
- **根因**：`_todayDashboardScrollable()` 查找 `ListView` 类型的 `Scrollable`，但之前的 TickerMode 修复迁移将 `ListView` 改为 `CustomScrollView`，导致查找失败。
- **修复**：`_todayDashboardScrollable()` 从 `find.byType(ListView)` 改为 `find.byType(CustomScrollView)`。

**3. ShellDeferredContent + 异步 Provider 时序（多个失败）**

- **文件**：`test/today/page_test.dart`、`test/today/ai_card_test.dart`
- **根因**：`ShellDeferredContent` 延迟到下一帧才构建真实内容，`todayDashboardProvider` 在内容构建后才开始异步获取数据，需要额外一帧让数据传播到 widget 树。`_settleDashboard` 和 `_scrollToSummaryCard` 的 `pump` 次数不足。
- **修复**：`_settleDashboard` 和 `_scrollToSummaryCard` 各增加一个 `await tester.pump()`。

**4. AI 要点默认折叠（3 个失败）**

- **文件**：`test/today/ai_card_test.dart`、`test/today/page_test.dart`
- **根因**：`TodaySummarySection` 的 AI 要点（bullets）默认折叠（`_aiExpanded = false`），测试直接断言 bullet 文本但未先展开。
- **修复**：新增 `_expandAiBullets` 辅助函数，在断言 bullet 文本前点击展开按钮（`l10n.todaySuggestionShowEvidence`）并等待动画完成。
