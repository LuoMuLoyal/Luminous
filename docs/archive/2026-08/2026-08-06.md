# 2026-08-06 Forui 0.24.1 → 0.25.0 升级

## 版本变更

- `pubspec.yaml`：`forui: ^0.24.1` → `^0.25.0`，`forui_hooks: ^0.24.0` → `^0.25.0`。
- 依赖解析：`forui 0.25.0`、`forui_assets 0.25.0`（Lucide 1.28.0）、`forui_hooks 0.25.0`。
- 前置条件：Flutter ≥ 3.44.0-0（本机 3.44.0 / Dart 3.12.0 满足）。

## 0.25.0 Breaking Changes 适配

- 逐一核对 0.25.0 changelog 的 8 项 breaking：项目**零命中**（不用 `FIconBuilder`/`FIcons.iconData`；
  16 处 `FTooltip` 均未传 `semanticsLabel`；无自定义 `barrierFilter`/`backgroundFilter`；
  无 `FBreadcrumb` / `FModalSheetStyle` / `FAnimatedModalBarrier`）。`flutter analyze` 一次通过。

## 图标桥接重新生成

- `scripts/generate_lucide_bridge.dart` 修复：`_defaultAssetsPath()` 原**硬编码 `forui_assets-0.24.0`**，
  导致重新生成时读到旧缓存（`circle-euro-sign` 图标在 0.25 中已改名 `circle-euro`，产生编译错误）。
  改为从 pub 缓存动态解析最新 `forui_assets-*` 版本；生成文件头版本号由路径推导，不再硬编码。
- 重新生成 `lib/core/design/lucide_icon_bridge.dart`：1991 → 2003 条（+12 新增、1 改名）。

## toast 测试恢复（TODO 债务清偿）

- `test/core/feedback/app_toast_test.dart` 新增 `Toast.show — with FToaster` 组：在镜像生产
  `FTheme → FToaster` 的测试壳中验证 toast 正常展示（返回 true、文案可见）并在 1800ms 后自动消失。
- 注：forui 0.25.0 非无障碍分支 `_startDismissing` 在**入场动画完成前** dismiss 会触发
  `dispose()` during `notifyListeners()`（其无障碍分支用 microtask 规避了同样问题）；
  测试中先 pump 300ms 让入场动画完成再触发计时器规避。
- `docs/00-current/TODO.md`：删除「Forui 0.23.0 FToaster LateInitializationError」债务条目。

## onDisabledPress 采纳评估（跳过）

- 原计划在 OAuth 登录按钮上采纳 `FButton.onDisabledPress`，核实后：OAuth 圆钮是自定义
  `GestureDetector` 组件而非 FButton/FTappable；项目其余 `onPress: null` 均为菜单 FTile 或已带 spinner
  的按钮，无自然落点。强行套用需改组件或新增 l10n 文案，收益小，**跳过**。
