# 2026-09-14

## refactor(record,health_data): 睡眠时段计算抽为领域服务,payload 键位统一为 startedAt/endedAt

### 背景

睡眠 payload 的时间键位在双仓长期不一致：Lucent 的 DTO 文档把 `startedAt` / `endedAt` 定义为正式键、
把 `startAt` / `endAt` 标为 legacy，但 Luminous 的创建页、编辑页、详情页、NLP 候选编辑器反而一直在
写读 legacy 键；服务端校验器则是两者都读（`startedAt ?? startAt`）。同时「就寝 + 起床 → 跨天时段」
这段时钟算术在创建页与编辑页各写了一份。

NLP 候选编辑器另有隐藏缺陷：用户改动时刻后它把值写成 `{hour, minute}` map，而服务端校验要求时间键
是 ISO 字符串，因此该路径保存必然校验失败。

### 变更

- 新增 `lib/features/record/domain/services/sleep_entry.dart`：`SleepEntryKind`（nightSleep / nap 及线上
  取值与解析）、`computeSleepDurationMinutes`、`resolveSleepWindow`（以**起床日**为归属日解析跨天时段，
  夜间睡眠最多跨一个午夜、小睡禁止跨天）、`validateSleepEntry`（缺时刻 / 起床不晚于就寝 / 小睡跨天 /
  小睡 > 3h / 夜间 > 16h）、`buildSleepPayload`（固定键位 `startedAt` / `endedAt` / `durationMinutes` /
  `sleepType`，加可选 `quality` 与设备侧分期）。
- 新增 `lib/features/record/presentation/utils/sleep_formatters.dart`：`sleepQualityOptions`、
  `formatSleepDurationLabel`、`formatSleepTimeRange`，取代原先散在 `sleep_structured_fields.dart` 与两处
  私有 `_formatDuration` 的重复实现。
- 创建页、编辑页改由领域服务构建 payload；详情页、编辑页、NLP 候选编辑器改读 `startedAt` / `endedAt`；
  NLP 候选编辑器改写时输出规范 ISO 时刻，map 形态的表示整体删除。
- 编辑页保留载入记录的 `sleepType`，避免编辑一条小睡时被改回夜间睡眠；只有时长、没有时刻的设备导入
  记录继续走「仅 durationMinutes」的兜底分支。
- `health_sync` 指纹计算去掉 `?? startAt` / `?? endAt` 回退。

### 验证

- `flutter analyze` 无问题。
- `flutter test test/record test/health_data` 全部通过。新增
  `test/record/domain/services/sleep_entry_test.dart`（跨天解析、小睡同日约束、两类时长上限、payload 键位与
  UTC 时刻往返）；原 `test/record/sleep_duration_test.dart` 由该测试取代删除；编辑页保留 duration-only
  payload 的断言更新为同时写入 `sleepType`。
