## A2UI 1.0：genui → a2ui_flutter，组件全量开放 + 双向交互

### 变更范围

**依赖**。`genui ^0.10.4`（pub 已标 discontinued）删除，换成 `a2ui_flutter ^0.5.0`
与 `a2ui_core ^0.9.0`（协议 v1.0）。连带移除 `genai_primitives`、`audioplayers*`
与 `video_player_win`——即 Windows 桌面端 `Video` /
`AudioPlayer` 没有平台实现，窗口里渲染不出来，网页/移动端可用。

**新接缝 `lib/core/composition/a2ui/`**（与旧 `core/composition/genui/` 一一对应，
旧目录整删）：

- `catalog.dart` — `GenerativeCatalog` 用 `basicCatalog()` 装配**全部**基础组件，
  `derive()` 成单一 catalog id `https://luminous.app/a2ui/catalog/v1.json`；
  `toDocument()` 产出给服务端提示词用的 catalog 文档。
- `transport.dart` — 封 `MessageProcessor<ComponentImplementation>`：`outbound`
  流（渲染端→agent 的 JSON）、`capabilitiesDocument()`、`dataModelSnapshot()`、
  `processMessages()`、`surfaceFor()`。
- `surface.dart` — `A2uiSurface` + **一套 framework `ThemeData`**。这一层是必须的：
  `a2ui_flutter` 内部全部 import `package:flutter/material.dart`，而本仓界面已迁
  `material_ui`，`foruiMaterialTheme()` 返回的是 `material_ui` 的 `ThemeData`，
  两套类型不通用——不套这一层，生成出来的卡片和输入框会回落 M3 默认色。
  亮度取 `material_ui` 的 `Theme.of(context)`（树里没有 framework `Theme` 祖先，
  用 framework 版本会断言失败）。

**组合根 `lib/app/composition/generative/catalog.dart`**：`CatalogItem` →
`ComponentImplementation`，builder 签名 `(context, node, props, buildChild)`，
取值走 `props.string` / `props.list`。三个领域组件保留（`metric_card` /
`trend_chart` / `finding`），仍从 Riverpod 取真值。

**`lib/features/generative/`**：

- `domain/services/catalog_policy.dart` **删除**；`shared/domain/generative/data_scope.dart`
  **删除**（只剩一个 `RangeKey` 还用得上，降级为 `shared/domain/generative/range_key.dart`）。
- `item_catalog.dart` 只剩 type 名与 enum 取值（进组件 schema）。
- `GenerationTurn` 新增；`GenerationRequest` 加 `capabilities`；文档值类型加
  `dataModel`。
- `GenerationSession.commit` 不再校验，新结果**覆盖**旧序列（服务端每轮返回完整序列）。
- `generation_remote.dart` 两个端点共用一条 SSE 消费路径，新增 `turn()`。
- `generation_cache.dart` 键改 `a2ui.<surface>.document`，存 `{messages, dataModel?}`。
- `providers/generation.dart` 订阅 `transport.outbound` 并驱动交互回合；回合串行化
  （`_turnInFlight`），并发第二回合直接丢弃。
- `providers/surface_state.dart` 新增 `generativeCatalogLocaleProvider`。

### 破坏性变更

**零兼容**。旧键 `genui.<surface>.surface` 没有读取、也没有清理路径：那一份存的是
v0.9 消息，这套代码重放不了。编排页的 `genui.<surface>.spec`（用户起的标题）与
生成结果无关，键不动。
