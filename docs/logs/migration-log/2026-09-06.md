## fix(mine): 「我的」页健康同步入口在 Web 端抛出 Unsupported operation

「我的」页 `account_security.dart` 的 `if (Platform.isIOS || Platform.isAndroid)` 缺少
`kIsWeb` 守卫:dart:io `Platform` 在 Flutter Web 上是桩实现,访问即抛
`Unsupported operation: Platform._operatingSystem`,导致该 tile 子树构建失败,在
「通知与提醒」模块下方整块渲染为红色报错。其余 Platform 调用点(`bootstrap.dart`、
`lucent_workspace.dart`、`shell/page.dart`、`search/content.dart` 等)均已有
`!kIsWeb &&` 前置守卫,仅此一处遗漏。改为与其他调用点一致的前置守卫后,Web 端该
入口隐藏、移动端行为不变(测试运行于 VM,`Platform.isIOS` 返回 false 不抛,故此前
单测未暴露)。

验证:`flutter analyze` 无新增告警;`test/mine/page_test.dart` 通过。
