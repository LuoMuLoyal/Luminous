## Luminous — 架构审查改进 #6：Riverpod provider 声明风格统一

- **目标**：统一 Riverpod provider 声明风格，修正 ADR-0006 完成宣称与事实不符

### 背景

ADR-0006 引入 `riverpod_generator` 后，分三批迁移了 network_providers、authGuarded 接入、
feature datasource/repository provider。但约 20 处手写 `Provider<T>` / `FutureProvider<T>` /

「全部迁移」的印象。同时约 25 处 `NotifierProvider` / `AsyncNotifierProvider`（Notifier 类）
保持手写，缺乏明确的取舍标准。

**手写 Provider/FutureProvider 全部迁移为 `@riverpod` 注解（~20 处）**：

  `final xxxDashboardProvider = FutureProvider<XxxDashboard>((ref) { ... })` →
  `@Riverpod(keepAlive: true) Future<XxxDashboard> xxxDashboard(Ref ref) { ... }`

- `medicine/presentation/providers/risk_check.dart`：`medicineRiskCheckProvider` + `redFlagAlertsProvider` 迁移

- `support/data/providers/resources.dart`：`supportResourcesProvider` + `appInfoProvider` 迁移
- `today/presentation/providers/suggestion.dart`：`suggestionHistoryProvider` + `suggestionExplanationProvider` 迁移
