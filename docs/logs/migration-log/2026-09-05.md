# Migration Log — 2026-09-05

## chore(api): dio 升级到 5.11.1 并适配新增枚举分支

`pubspec.yaml` dio 由 ^5.9.2 升到 ^5.11.1,`pubspec.lock` 同步锁定 5.11.1。dio 5.11 新增 `DioExceptionType.transformTimeout`(响应数据转换阶段超时),三处穷尽 switch 补分支:retry 策略将 transformTimeout 归入可重试超时类;错误映射归为 receiveTimeout 语义的网络超时并补 fallback 文案。对应测试补用例:`retry_policy_test.dart` 补 transformTimeout 可重试断言,`target_error_contract_test.dart` 映射表补 transformTimeout→receiveTimeout 条目,`dio_client_test.dart` 补 fallback 文案断言。
验证:整仓 flutter analyze 零问题;network 目录测试与全量测试通过。

## chore(contract): openapi-generator 版本提升到 7.25.0

`openapitools.json` 的 generator-cli version 由 7.22.0 升到 7.25.0。OpenAPI 3.2 双轨方案经实测不可行(dart-dio 生成器对 OAS 3.1/3.2 的 required+nullable 有上游 bug #21510/#23866,且输入侧不支持 3.2),维持 Lucent spec OAS 3.0 直出,客户端经 bootstrap 用 7.25.0 再生成,产物与升级前零 diff。
验证:bootstrap 端到端通过,generated/lucent_api 相对再生成前无漂移。
