## fix(core): 头像选图裁剪失败提示改用 State.context，消除 context 寿命风险

（计划 W1 / W2。）

### 变更

- `lib/core/widgets/common/avatar/avatar_draft.dart`：
  - `_showCropFailure(BuildContext)` 收参数改为无参，直接使用 `State.context`，
    入口加 `if (!mounted) return;`。`onCropped` 回调开头本已有 `if (!mounted) return;`，
    但现在规则固化为「失败提示只在 State 仍挂载时展示」，杜绝未来从 dispose 路径
    误把失效 context 传给 `Toast.show` 的可能。
  - `pickAvatarDraft` doc 补一段「调用方需保证传入的 context 在 await 边界后仍
    mounted（例如 dialog / showModalBottomSheet 内部），否则空文件/裁剪失败等
    反馈 Toast 会静默不显示」——把 `context.mounted` 约定从代码显式化到签名文档，
    与 W1 同一组改动一起收敛。

### 验证

- `flutter analyze` 全仓无问题；`flutter test test/core/widgets/avatar_draft_test.dart`
  通过（原有 2 条用例，本次改动不涉其断言路径）。
