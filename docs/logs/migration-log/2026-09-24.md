### 台账裁决（08-23 错误迁移审查遗留批次）

以下项按「已接受/不必做」结案，条目已从 `docs/TODO.md` 删除；box_scan 候选循环一项按上文实现：

- RetryInterceptor 链级 `retryAfter` 断言：RetryPolicy 单测已覆盖优先级，链级用例需真实计时（易抖），不补。
- 畸形错误体端到端暴露形态：`DioException(error: FormatException)` 是 dio 归一化既有行为，保留。
- 认证 `_revokeFailure` 用 `StackTrace.current`：`LucentFailure.cause` 已带原 `DioException`，可调试，不追。
- `_resolve` 三处同构适配器：风格级重复，不抽公共 helper。
- box_scan AI 流无独立 widget 测试：AI 路径含真实文件 I/O，按既有排除清单只做 repository 层覆盖。
- 两页 network/business 通用文案：迁移前既有行为，暂不按 kind 区分。
- 非 problem+json 错误体的 `FormatException` 逃逸无 repository 层日志：页面通用 catch 已吸收，不补日志。
- `legal_list_page_test.dart` 的 `Object? error` 装饰参数：测试内遗留，不影响判定，不改。
- `NetworkErrorCode.invalidSsePayload`：运行时无产生点，但枚举 + l10n + pending sync 序列化要兼容历史
  持久化行，保留。
- `_ErrorSseAdapter` 三份复制：沿用每文件自带测试辅助的惯例，不收敛。
