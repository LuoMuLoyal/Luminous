## refactor(core): core 层去除 feature 依赖（C6 / R7）

`core_not_import_features` 从 11 条降到 0。手法统一为「core 定义抽象、`lib/app/`
组合根注入实现」——core 侧不再出现任何 `lib/features/**` 的 import，feature 侧也
没有被要求反向配合（只跟随改了 import 指向）。

### 处置

- **`core/database/sync/handlers.dart`**：抽出 `SyncHandlerRegistrar`
  （`name` / `register(ProviderContainer)`）与 `syncHandlerRegistrarsProvider`；
  原来直接读的 medicine / record / health_context / analytics 四个 provider，
  改由 `lib/app/sync_handlers.dart` 的四个注册器提供，`registerSyncHandlers`
  只遍历注册器列表。后台 isolate 经由同一个 `appProviderOverrides` 复用。
- **`core/auth/session_state.dart` + `session_provider.dart`**：会话状态不再引用
  `features/auth/domain` 的 `AuthUser`。core 新增 `SessionSnapshot` /
  `SessionUserSnapshot`（含 linkedIdentities 等展示字段）作为中性值类型；
  `AuthSessionState.user` 声明为 `Object?`（core 只存不命名），并新增
  `userSnapshot`（core 读这个）与 `userId` 便捷 getter。
- **`core/auth/session_gateway.dart`**：新增 `AuthSessionGateway`
  （`fetchAccount` / `refreshSession` / `logout`）接口，替代原来的
  `authRepositoryProvider` 直接依赖；由 `lib/app/auth_session_adapter.dart` 的
  `FeatureAuthSessionGateway` 实现，并在那里同时提供
  `AuthUser`/`AuthSession` → 快照的 extension 与 `appProviderOverrides`。
- **`core/auth/sensitive_action_password_resolver.dart`**：新增
  `SensitiveActionPolicy` 端口，由 `lib/app/settings_adapters.dart` 的
  `FeatureSensitiveActionPolicy` 读 `userSettingsControllerProvider`。
- **`core/push/message_handler.dart` + `lifecycle.dart`**：新增
  `PushEventHandlers`（`onReceive` / `onOpen`）与 `PushPermissionProbe`、
  `PushPermissionStatus`、`PushAction` / `pushActionOf`；未读计数与今日分析
  失效改由 `lib/app/push_handlers.dart` 的 `FeaturePushEventHandlers` 承担，
  推送动作字符串在 core 内化，不再 import `features/today` / `features/notification`。
- **组合根**：`main.dart` 改为先建 `ProviderContainer`、`updateOverrides(
  appProviderOverrides(root))` 后 `UncontrolledProviderScope` 注入，测试仍可直接
  用 `ProviderContainer(overrides: [...])`。
