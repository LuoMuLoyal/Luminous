### Material / Cupertino 迁移（3.50 核心 breaking）

3.50 弃用 framework 版 `package:flutter/material.dart` / `cupertino.dart`
（迁移目标 `material_ui` / `cupertino_ui`）。本仓 app 根此前已是 material_ui
的 `MaterialApp`（`lib/app/bootstrap.dart`），本次用
`dart fix --apply --code=migrate_design_widgets`（随全量 `dart fix --apply`，
共 1103 fixes / 551 files）把剩余约 250 处 framework material 导入迁到
material_ui / cupertino_ui；pubspec 新增 `cupertino_ui: ^1.0.1`。

### 混合类型世界的接缝（dart fix 处理不了、手修的 4 处）

material_ui 是真 fork 库（非 re-export shim），与仍建在 framework material
上的依赖并存时产生双 `ThemeData` 世界。gen_ai（`flutter_gen_ai_chat_ui`）、
`flutter_markdown_plus` 与 `genui` 最新版均未迁 material_ui，其公开 API 期望
framework 类型。以下文件按职责显式保留 framework 导入（行内附理由豁免弃用
提示）：

- `lib/features/assistant/presentation/widgets/chat_theme_bridge.dart`：
  职责就是把 Forui token 翻译成 framework `ThemeData` 供 gen_ai 消费。
- `lib/features/assistant/presentation/widgets/chat_surface.dart`：
  `InputOptions.decoration` 期望 framework `InputDecoration`。
- `lib/core/design/tokens/markdown_style.dart`：
  `MarkdownStyleSheet.fromTheme`（flutter_markdown_plus）期望 framework `Theme`。
- `test/desktop/keyboard_shortcuts_test.dart`：
  被测对象 `AppShortcuts` 建立在 framework widgets 之上；Global delegates 用
  `mui.` / `cui.` 前缀消歧（参照 `sensitive_action_password_resolver_test`
  既有模式）。

### 测试侧的类型归属修复（dart fix 静默换类型导致的回归）

`dart fix` 把测试文件里 framework material 的导入换成了 material_ui，但
**对 framework 组件做类型断言的 finder / `tester.widget<T>` 随之静默换了
类型归属**，产生 29 个 assistant + 1 个 generative 测试失败。根因全部一致，
修复方式是把这些断言显式指回 framework 类型：

- `test/assistant/page_test.dart`：`f.TextField` / `f.Theme` → `fw.` 前缀
  （framework material）。gen_ai composer 的 `TextField` 是 framework 类型，
  对 material_ui 类型找永远 0 命中。
- `test/generative/generative_surface_test.dart`：`Card` / `Row` / `Column`
  等 `find.byType` → `fw.` 前缀（`genui` 的 A2UI 组件建在 framework material
  上）。
- `test/helpers/test_forui_app.dart`：`dart fix` 把 delegates 列表里的
  framework 版 `GlobalMaterialLocalizations` 换成了 material_ui 版，而 gen_ai
  的 `TextField` 需要 framework `MaterialLocalizations`——两套 delegate
  注册的是不同接口类型，**都需要**。framework 三件套经 `fl.` 前缀显式加回，
  material_ui / cupertino_ui 版保留（forui 需要），文件级
  `ignore_for_file: deprecated_member_use`。
- `integration_test/support/e2e_test_helpers.dart`：初次 fix 漏扫
  （`flutter analyze` 默认覆盖，`dart fix` 目录遍历当时未触及），补跑修复。
