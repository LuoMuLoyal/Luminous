# 迁移日志 2026-10-18

## refactor(assistant): 对话渲染层从 flow_ui 迁移到 flutter_gen_ai_chat_ui

- 动机:`flow_ui` 0.x 为单维护者、pub 数据量低(28 likes / 749 下载),assistant 对话
  框 / 流式生成 / 工具来源 / 思考态全押在它上面;`flutter_gen_ai_chat_ui`(gen_ai)
  2.20.0 社区数据高一个量级、MIT、活跃维护。计划与 P0 裁决见(已完成的)
  `plans/2026-10-18-assistant-chat-ui-migration.md`。
- 范围:只换**客户端渲染层**。后端契约(SSE chunk/result/error/done、capabilities、
  proposal confirm)不变;`domain/` / `data/` / `application/` 未动;不 import
  `lib/core/ai`;canonical 消息 id 仍由 `presentation/utils/message_id.dart` 决定。

### 依赖与生成物

- `pubspec.yaml`:移除 `flow_ui: ^0.3.0`,新增 `flutter_gen_ai_chat_ui: ^2.20.0`;
  其后 `flutter pub get`(传递依赖 `flutter_markdown_plus` / `url_launcher` / `clock`
  已有,未重复声明)。
- `lib/oss_licenses.dart` 重生成(gen_ai 在内、flow_ui 计数为 0)。
- `material_ui` 保留:它是 app 根 `MaterialApp` 的载体,不随 flow_ui 一起删。

### 主题桥(关键决策)

- 新增 `presentation/widgets/chat_theme_bridge.dart`:`luminousChatTheme` 把 Forui
  语义 token 桥成一层 framework `ThemeData`(+ `CustomThemeExtension`),
  `withLuminousChatTheme` 仅包裹 assistant 子树(外挂透明 framework `Material`)。
- gen_ai 建在 framework `package:flutter/material.dart` 上,而 app 根是 `material_ui`
  的 `MaterialApp`——framework `Theme.of` 在根下**恒为 M3 默认浅色**(实测
  `brightness=light`、`primary=#6750A4`)。因此桥**必须显式设 `brightness`/
  `colorScheme`**,亮度只从 Forui(`context.theme.colors.brightness`)读取,不能继承。
  代价是 assistant 子树内并存两套 Material(根 material_ui、子树 framework)。
- 删除 `flow_theme_bridge.dart`。

### 适配与渲染

- 新增 `presentation/widgets/chat_adapter.dart`(`AssistantChatAdapter`):
  `mapMessages`/`mapMessage`/`mapStreamingDraft`/`mapLoading` 做 domain→gen_ai
  view-model 映射(不持有状态);列表身份 = `customProperties['id']` =
  `$conversationId:$index:$canonical`,与领域 id 解耦;助手消息在
  `customProperties['assistantMessage']` 挂回原 `AssistantMessage` 供 chrome 渲染。
- 新增 `presentation/widgets/chat_surface.dart`(`AssistantChatSurface`):持有
  `ChatMessagesController`,把 SSE 生命周期经 `ref.listen` 镜像到
  `setStreamingMessage`/`stopStreamingMessage`(稳定 id `assistant:streaming`),
  驱动流式 caret;**不在 build 内调用**(避免 build 期 notify)。
- `page.dart` 用 `withLuminousChatTheme` 包裹;`page_body.dart` 改用
  `AssistantChatSurface`;删除 `flowui_adapter.dart`、`composer_host.dart`、
  `views/conversation_message_list.dart`。
- 富渲染按计划 §四:gen_ai 自带气泡(markdown/流式 caret,底色取
  `CustomThemeExtension.messageBubbleColor` = Forui `colors.secondary`),来源条 /
  免责声明 / proposal 卡 / copy·regen 动作行经 `MessageOptions.bubbleBuilder` 追加在
  气泡下方;gen_ai 自带 action row 关闭(`showCopyButton:false`/`showTime:false`),
  改由自研 `_ActionRow` 以保留 l10n 文案。**行为差异**:旧 `flowui_adapter` 的
  `_AssistantReplyPanel` 曾把整条消息(含 footer)包进 `colors.secondary` 面板;新结构
  下 chrome 落在气泡下方、页面背景上。
- 输入:改用 gen_ai `InputOptions`(保留 `textController` 与 l10n 占位符);门控仍以后端
  `canSendMessages` 为准;禁用且无会话时以 `StateMessageView` 替代。
- 空态:`empty_conversation.dart` 不再自己滚动/居中(gen_ai 在
  `centerVertically:true` 时已用 `SingleChildScrollView`+`Center` 包裹
  `WelcomeMessageConfig.builder`),只做收缩高度的内容排布,消除嵌套滚动与无界高度约束。
- `empty_support.dart` 的 `FlowSuggestionGroup` → forui `FTile`;
  `assistant_greeting.dart` 解除 flow token 依赖,改 Forui 语义 token。

## fix(assistant): 用户气泡改淡蓝、消息顺序改为用户在上流式在下

- 气泡底色:主题桥 `userBubbleColor` 由 `SemanticColor.primary.solid`(品牌深蓝)改为
  `SemanticColor.primary.muted`(alpha≈0.10 淡蓝);气泡文字取
  `CustomThemeExtension.messageTextColor`(= `colors.foreground`),深色文字在淡蓝底上可读。
- 消息顺序:gen_ai `PaginationConfig.reverseOrder` 默认 true(index 0 = 最新,渲染在底部),
  但 `chat_adapter.mapMessages` 此前按域内时间正序输出 → 用户消息被排到最新、流式回复排在其上。
  改为按域内 index 倒序输出(newest-first),流式草稿 / 打开会话 loading / 发送失败重试行
  仍固定在 index 0(即最底部锚点);canonical 消息 id 不变。
- 文件:`chat_theme_bridge.dart`、`chat_adapter.dart`、`chat_surface.dart`;
  测试 `test/assistant/chat_adapter_test.dart` 顺序断言同步。
- 验证:`flutter analyze` 零问题;`flutter test` 全量通过。

## fix(search): 搜索严格提交触发,来源切换不再自动重搜

- 问题:provider 早已是提交式(`updateQuery` 不触网,已有测试钉住),但结果面板由
  `state.query.trim().isNotEmpty` 门控——一输入就渲染「共找到 0 条结果」+「无结果?」面板,
  读起来就是「有内容即搜」;触发入口也只是随文本出现的行内小图标,不易发现。
- 状态:新增 `MedicineSearchState.submittedQuery` 与 `hasSubmittedResults`
  (`submittedQuery == query.trim()`)。`_doSearch` 记录提交词;`updateQuery` 一旦发现文本与
  已提交词不一致(含清空)就清 `submittedQuery`、清 results/selectedResultId/detailPreview、
  递增 generation(作废在途搜索);`switchSource` **不再搜索**,只切来源 + 清结果。
- UI:`SearchInput` 改为左输入框 + 右「搜索」按钮(新增 l10n `medicineSearchSubmitAction`),
  空输入时按钮禁用;`content.dart` 两个布局的结果/建议区块改由 `hasSubmittedResults` 门控。
  键盘 search 键/回车(`textInputAction` + `onSubmit`)与按钮为仅有的两个触发器。
- 文件:`presentation/providers/medicine_search.dart`、`widgets/sections/input.dart`、
  `widgets/views/content.dart`、`features/search/README.md`、`lib/l10n/src/medicine_{zh,en}.arb`;
  测试 `test/search/page_test.dart`、`test/search/presentation/providers/medicine_search_notifier_test.dart`。
- 验证:`flutter analyze` 零问题;`flutter test test/search` 与全量 `flutter test` 通过。
