# 2026-11-05

## style(shell): 桌面侧边栏收敛为「整列一个底色」，分组只靠排版表达

### 问题

桌面端五 tab 侧边栏读起来是「每个标题各自独立」的一条条模块，而不是分组导航。
根源是 `FSidebarItemStyle.inherit` 给每个条目都铺了 `colors.background`：
条目底色比侧边栏底色亮一档，且**每条各成一块**，一列排下来就是几块各自浮起的
行；再叠上 `FSidebarGroupStyle` 默认的 `childrenPadding`（每组末尾垫 16px），
组与组之间的间距全部由它撑开，分组标题反而没有分量。

### 落地

- 新增 `lib/features/shell/presentation/sidebar/desktop.dart`：结构仍是 Forui 的
  `FSidebar` / `FSidebarGroup` / `FSidebarItem`，只覆写 style。
  - 条目底色：非交互态**透明**，选中 `colors.card`、悬停 `colors.muted`。
  - 条目文字/图标：未选中用 `mutedForeground`，选中转 `foreground` 并加重字重。
  - 分组标题：上方 `Spacing.xl3`、下方 `Spacing.xs`，`childrenPadding` 归零，
    组内条目间距 2。
  - 侧边栏底色取 `scaffoldStyle.sidebarBackgroundColor`，**不画描边**——层次靠
    色差，不靠边框/阴影/分组卡片。
- `ShellPage` 只负责留白与 `SafeArea`（macOS 红绿灯），侧栏形态全部移出。
- **变体值必须是完整值，不能是 delta**：Forui 的 `FVariants.resolve` 按约束挑候选
  后**原样返回**候选值，不把它当 delta 作用在 base 上；因此 `textStyle`/`iconStyle`
  的变体写成 `TextStyleDelta` / `IconThemeDataDelta` 会让未命中变体的状态取到空色，
  条目直接看不见。

### 验证

`flutter analyze` 无问题；`flutter test test/shell` 通过（侧栏断言已从
`FSidebar`/`FSidebarItem` 计数改为 `DesktopSidebar` + 五个 tab 的 test key）；
`luminous_lints --clean-layers` 与改动前同数（无新增违规）。
