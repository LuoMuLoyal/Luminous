# 迁移日志 2026-10-03

## fix(today): 主建议卡头部与次级操作区排版修正

### 背景

今日页主建议卡（`suggestion_primary_card.dart`）在三处排版上偏离设计意图：

1. 头部左上角有多余的 glyph 图标块（`TodayGlyphTile`），挤占标题横向空间；
2. 标题位于图标块下方，被视作独立一行，导致标题与右侧主操作按钮不在同一行；
3. 「次级操作」（`secondaryActions`）与「查看依据」（`EvidenceToggleButton`）分属两个
   独立区块，各占一行，垂直空间被浪费。

此外 e2e 截图 fixture 与后端契约不符，放大了上述问题：`cardTone` 用了 `warning`
（后端 `COMPLIANCE` 为 `urgent`），`feedbackOptions` 缺 `suppress`，且次级操作标签
误用 `稍后提醒`（`actionId: 'later'`）——与反馈行中同样本地化为「稍后提醒」的
`later` 反馈重复，页面因此出现两处「稍后提醒」。

### 变更

- `presentation/widgets/sections/suggestion_primary_card.dart`
  - 删除头部 `TodayGlyphTile` 图标块及其下 `SizedBox`；标题改用 `Expanded` 与主操作
    按钮合并进同一 `Row`（`crossAxisAlignment: center`），标题独占弹性空间、按钮
    `mainAxisSize.min` 靠右。
  - 次级操作与「查看依据」合并为**单个左对齐 `Wrap`**（`spacing`/`runSpacing` 用
    `Spacing.sm`，`WrapCrossAlignment.center`）。选择 `Wrap` 而非左右两端对齐，是为了
    在无次级操作时自然退化为仅「查看依据」，窄屏时靠 `runSpacing` 换行而不溢出。
  - 移除随之变为孤儿的 `shared/components.dart`、`shared/suggestion_icon_mapping.dart`
    导入（`TodayGlyphTile` 仍由次级建议卡 `suggestion.dart` 使用）。
- `presentation/widgets/sections/suggestion_state_views.dart`
  - `SuggestionSkeleton` 头部镜像新卡结构：标题条 + 右侧胶囊按钮占位同处一行，其后
    两行原因占位，再是次级操作胶囊与「查看依据」长条占位（去掉原图标方块）。
- `integration_test/support/screenshot_fixtures.dart`
  - `cardTone` 改为 `urgent`；`primaryAction` 明确为 `go_confirm`（去确认）；
    `secondaryActions` 改为后端真实产出的 `skip_dose`（跳过此次）并带上跳转 query；
    `feedbackOptions` 补 `suppress`。

### 验证结论

- `flutter analyze lib/features/today test/today integration_test` 无问题。
- `flutter test test/today/` 全绿；新增主建议卡布局断言（标题与主操作同行、头部无
  glyph 图标、次级操作与「查看依据」同行且左→右排列、无次级操作时「查看依据」仍在）。
- `flutter test` 全量通过。
- 版面实测（真实 `TodayPage`，含页面内边距）：标题在截图宽度（逻辑约 432px）保持
  单行，约 412px 起换行属预期；360px 与 1.3 倍字缩放均无 `RenderFlex` 溢出。
- 未改动任何 l10n 分片或生成文件；`app_*.arb` 与 `generated/lucent_api` 无变化。

## test(screenshots): 新增宿主端全站仿真数据截图生成器

### 背景

需要一次性产出全部 45 个页面目录项、且每页都有仿真数据填充的截图,用于文档与
汇报材料。原有 e2e 路径依赖 Android 模拟器,约 3 s/页;而 `flutter_test` 走假时钟
在宿主端栅格化,约 0.7 s/页。

### 变更

新增 `tool/screenshots/`(不参与 CI:`flutter test` 只扫描 `test/`,产物目录
`outputs/` 与 `build/` 均已 gitignore):

- `generate.dart` — 仅从 `integration_test/screenshots/page_catalog_screenshot_test.dart`
  导入**页面目录常量**(路由与文件名),不复用任何 e2e fixture/helper/假数据。
  逐页构建 `ProviderContainer(retry: null)` → `router.go` → `matchesGoldenFile`。
- `simulated_fakes_shell_a.dart` / `simulated_fakes_shell_b.dart` /
  `simulated_fakes_misc.dart` / `simulated_fakes_review.dart` — 为本生成器全新编写的
  中文仿真数据(陈静 / 2026 年 / 高血压 + 2 型糖尿病 / 3 种当前用药),
  不含 `E2E User`、`[DEMO]` 等占位串。
- `contact_sheet.py` — 把 45 张截图拼成 3 张联系表,便于快速过目。
- `README.md` — 运行方式与踩坑说明(字体注册、`matchesGoldenFile` 是唯一可用栅格
  路径、定时器残留、插件通道桩、占位 id 映射)。

两处非显而易见的数据接线已固化在生成器内并在 README 说明:五个 shell tab 需要
override `authSessionProvider` 才会渲染已登录内容;提醒页面读的是
`medicineReminderRemoteDataSourceProvider` 而非 `reminderRepositoryProvider`。
另需把目录中的 e2e 占位 id(`e2e-allergy-1`、`__mock_cn_ibuprofen__` 等)映射到仿真
数据集,且不得改动已提交的页面目录本身。

### 验证结论

- `flutter analyze` 全仓无问题。
- `flutter test tool/screenshots/generate.dart --update-goldens` 45/45 通过,宿主端
  约 30 s(对比 e2e 模拟器路径约 230 s)。
- 45 张截图与 `MANIFEST.md` / `_rendered_text.txt` 均已产出;逐页复核无空态/错误态
  文案(「记录不存在」「暂时无法展示」「相机权限被拒绝」等命中数为 0)。
- 未改动 `lib/`、l10n 分片、`integration_test/screenshots/page_catalog_screenshot_test.dart`
  或任何生成文件。

## test(screenshots): 补充助手能力与药物图检索截图

### 背景

页面目录每页只截一张,助手对话页只有静态首屏。而真正体现助手能力的状态需要交互
才会出现:工具写入提案的**确认卡**、取消/过期、来源条展开、能力面板、会话抽屉、
重新生成后的旧回答灰态;药物图检索(拍药盒识别)更是没有任何路由,只能在搜索页
按压入口才会弹出方式选择与识别结果。

### 变更

- 新增 `tool/screenshots/simulated_fakes_assistant.dart` — 为本生成器新写的助手
  会话伪造数据:待确认的 `create_daily_record` 提案(含 `previewFields`/`target`/
  `constraints`/`payload`)、已确认态、带溯源引用与覆盖度差异的工具信封、被替换的
  旧回答,以及药盒识别候选结果。
- `simulated_fakes_misc.dart` — `SimulatedAssistantRepository` 支持注入会话
  (`SimulatedAssistantRepository(conversation: …)`);`getCapabilities()` 的工具清单
  从 3 个扩展到 12 个(用 `ui_formatters.localizeToolName` 真实映射的 id,含一个未
  授权工具以展示禁用态)。
- `generate.dart` — 抽出共用的 `capture(...)` 主体,并新增 `_extraCaptures` 九张
  补充截图(46–54):助手待确认提案 / 已确认 / 来源条展开 / 能力面板 / 会话抽屉 /
  旧回答灰态,以及药物图检索的方式选择、OCR 结果、AI 结果(候选列表展开)。
  补充截图驱动的是真实组件(`showMedicineBoxScanSheet`、`MedicineRecognizeDialog`、
  `AssistantProposalCard`),不是为截图另做的界面。
- `tool/screenshots/fixtures/medicine_box_photo.png` — 仅作为识别结果缩略图的合成
  药盒照片,不属于应用内容。(后改为 `_ensureBoxPhoto` 在截图时用 Canvas 现画到系统
  临时目录,不再提交二进制。)
- `README.md` — 补充补充截图清单、对话框宿主 context 与图像解码两个坑。

补充截图的两个技术点:应用的 `Localizations`/`Navigator` 建在 `LuminousApp` 内部,
根 element 两者都没有(`showAppDialog` 会在 `Navigator.of` 断言),故取 navigator
的首个子节点作为宿主 context;`Image.file` 的异步解码在假异步测试区内不会完成,
缩略图会截成空白,需先在 `tester.runAsync` 里 `precacheImage`。另外
`AssistantProposedAction.isExpired` 比较 `clock.now()`,提案的 `expiresAt` 必须相对
真实时钟生成,否则卡片会渲染成已过期、确认按钮被禁用。

### 验证结论

- `flutter analyze` 全仓无问题。
- `flutter test tool/screenshots/generate.dart --update-goldens` 54/54 通过,宿主端
  约 45 s(45 张目录页 + 9 张补充截图)。
- 逐页复核补充截图内容正确:确认卡显示「待确认」且确认按钮可点、确认态转为「已确认」
  且文案改为已写入、来源条展开显示覆盖度/置信度/歧义/来源表/溯源引用、能力面板显示
  「可用 11 / 12」、OCR 与 AI 结果分别显示对应提示与候选匹配方式。
- 错误态复核:唯一命中「重试」的是同步失败详情页本身(该页设计如此),无空态/错误态
  截图。
- 未改动 `lib/`、l10n 分片、`integration_test/screenshots/page_catalog_screenshot_test.dart`
  或任何生成文件。

## chore(ci): workflow 按关注点拆分并规范化命名

### 背景

`luminous-ci.yml` 与 `luminous-cd.yml` 的文件名带项目名前缀,与 Lucent 侧
(`ci.yml` / `release.yml` / `docker.yml`)不一致;职责上 CI 与发布混在两个文件里,
权限只能整体授予。

### 变更

拆为两个按关注点划分的文件(`luminous-ci.yml` / `luminous-cd.yml` 已 `git rm`):

| 文件 | `name:` | 职责 | 触发 |
| --- | --- | --- | --- |
| `ci.yml` | `CI` | analyze / 单测 / 生成物一致性 / 文档校验;main 上额外出 APK | push, PR, 手动 |
| `deploy-web.yml` | `Deploy web` | 构建 Flutter Web 并发布 GitHub Pages | push(`refactor`), 手动 |

- job 内容逐字迁移,步骤顺序与 flutter 版本不变;**自动触发条件原样保留**
  (`deploy-web.yml` 仍只在 `refactor` 分支 push 上自动触发,未顺手改成 `main`)。
- `permissions` 收窄到各文件实际所需:`ci.yml` 仅 `contents: read`;
  `pages: write` / `id-token: write` 只留在 `deploy-web.yml`。
- 新增 `.github/workflows/README.md` 记录各文件职责与触发约定。
- 文档同步:`README.md`、`docs/explanation/project-governance.md`、
  `docs/explanation/ai-development-workflow.md` 中过期的 workflow 文件名引用已更新。

### 验证

- workflow YAML 解析 + 结构 lint(含 `needs`/`uses` 引用与 workflow 名唯一性)通过。
- 生成物一致性、`flutter analyze`、`flutter test` 由 CI 承接;本次仅移动 workflow
  定义,未改动任何 Dart 源码、l10n 分片或生成文件。
