# 2026-09-12

## docs(design): 动画体系调研与选型——全局分级动画 Motion Hierarchy

纯调研落地,不改任何代码。

### 背景

用户反馈:进入/退出登录页有动画,但其他区域几乎无动画 —— tab 切换、设置页点击进入
子页、路由进入/退出都缺过渡;要求按分级(motion hierarchy)调研"官方 vs 社区包"
后选型,让软件更流畅。

### 调研过程(两份并行 subagent 调研 + 本地审计)

1. **本地代码审计**(本仓库):`lib/app/router_helpers.dart` 已有 `fadePage` /
   `tabFadePage` / `slidePage` / `sidePanelPage`;`MotionTokens` / `DurationTokens`
   已建(4 曲线 + 8 时长);`flutter_animate` 4.5.2 已依赖但仅 ~6 处使用;显式
   `AnimationController` 3 处;`Hero` 零使用;无 `AnimatedList`;Forui `FTheme`
   自带 `FThemeMotion` 主题切换动画(200ms);flow_ui 0.1.0 自带流式/呼吸动画。
2. **官方调研**(Flutter 3.38+ 源码与文档、go_router 17.x、M3 motion 规范):
   - `StatefulShellRoute.indexedStack` 官方明确**分支切换无过渡**,须自定义
     `navigatorContainerBuilder`(官方示例 custom_stateful_shell_route.dart),
     M3 称此模式为 Fade through(淡入+轻微缩放,≈300ms)。
   - 子页面路由首选默认 `MaterialPage` + `PageTransitionsTheme`(平台原生、零配置);
     特殊页才用 `CustomTransitionPage`。
   - `PageTransitionsTheme` 默认:Android=PredictiveBack(回退 FadeForwards,450ms)、
     iOS/macOS=Cupertino、Windows/Linux=Zoom(快照,Web 自动禁)、兜底 Zoom。
   - M3 分级:navigation 300–600ms / transitions 200–400ms / micro-interactions
     100–200ms;easing:standard=`(0.2,0,0,1)`、emphasized=`Curves.easeInOutCubicEmphasized`。
   - Hero 跨 StatefulShellRoute 分支不工作(独立 Navigator,#192043)。
   - reduce motion:`MediaQueryData.disableAnimations` 引擎驱动,框架动画自动压缩;
     iOS reduceMotion 暂不互通(#190287 在途)。
3. **社区包调研**(pub.dev/GitHub 实时数据):
   - Flutter 生态正迁向独立 `material_ui` 包(3.47 起),项目**已依赖 material_ui
     1.x**,与 `forui 0.26`、`animations 3.0.0` 同源。
   - `flutter_animate` 4.5.2 维护停滞(2024-11 起),CurvedAnimation 泄漏 bug 未修;
     活跃 fork `flutter_animate_plus` 是升级预案。
   - 推荐:tab 过渡**不引包自写**(navigatorContainerBuilder 20 行);可选引入官方
     `animations 3.0.0`(SharedAxis/FadeThrough;注意 OpenContainer 与 go_router
     不兼容 #121929,勿用于路由);明确不引入 page_transition / motion(GPL-3)/
     rive / lottie / go_router_animated_branch。

### 结论(选型)

三层动画体系,不引大包:

1. **导航过渡**:tab 切换自写 `navigatorContainerBuilder` fade-through(280–300ms
   emphasized);子页面路由先增强现有 `slidePage` 补 `secondaryAnimation` 反向过渡,
   再评估收敛到 `PageTransitionsTheme` 平台默认;设置页桌面 master-detail 加
   `AnimatedSwitcher`。
2. **内容/列表过渡**:flutter_animate 交错进场(限核心列表页)+ `AnimatedSwitcher`
   数据刷新 + Hero 限同分支。
3. **微交互**:优先 Forui 自带(FTappable/FPopover/FTooltip motion +
   `FAccessibilityMotion` 自动降级),flutter_animate 补充自由编排。

无障碍:框架动画自动响应 disableAnimations;自写显式动画统一经 AnimationController
并判断 `MediaQueryData.disableAnimations`;flutter_animate 使用处需补该判断(现状未做)。

## feat(shell,settings): Tab 切换 fade-through + 设置页桌面 master-detail 切换动画

动画体系阶段 2(核心痛点)落地。纯前端动画,无后端/契约/l10n 变更。

### Tab 切换(M3 fade-through)

- **根因**:`StatefulShellRoute.indexedStack` 官方明确"分支切换不做过渡"
  (各分支独立 Navigator,`PageTransitionsTheme` 管不到);`tabFadePage` 在分支
  常驻后不再重放,故五 Tab 切换是瞬间跳变。
- **方案**:按官方 custom_stateful_shell_route 示例,`router.dart` 改用一般
  `StatefulShellRoute` + 自定义 `navigatorContainerBuilder`,新增
  `ShellTabBranchContainer`(`lib/features/shell/presentation/tab_branch_container.dart`):
  - 切 Tab 时新分支淡入 + 轻微缩放(0.98→1.0),旧分支淡出(260/200ms,
    `MotionTokens.emphasized`)。
  - **保持 IndexedStack 语义**:所有分支常驻挂载(状态保留);非当前分支
    `Offstage`(对 finder/测试 offstage,与原来一致);隐藏分支
    `TickerMode(enabled: false)` + `IgnorePointer`。
  - 动画时长有界,`pumpAndSettle` 可收敛(全量测试验证)。
- `motion.dart` 新增 M3 对齐 token:`MotionTokens.emphasized`(=
  `Curves.easeInOutCubicEmphasized`)、`emphasizedDecelerate`(=
  `Cubic(0.05, 0.7, 0.1, 1)`)、`DurationTokens.tabFadeThrough`(260ms)/
  `tabFadeThroughOut`(200ms)/`masterDetailSwitch`(220ms)。

### 设置页桌面 master-detail

- `settings/presentation/widgets/master_detail.dart` 右侧 pane 包
  `AnimatedSwitcher`(220ms,`emphasizedDecelerate` 入场,`KeyedSubtree` 按
  `_selectedIndex` 触发),左栏点选切换分组时淡入淡出,替代原 `setState` 直接换 body。

### 测试

- `master_detail_test.dart`:"selecting a different group displays its body"
  从 `pump(150ms)` 改为 `pumpAndSettle()`(动画完成前旧 pane 仍在淡出,
  原断言在动画语义下不成立;真实用户看到的是动画完成后的状态)。
- 验证:`flutter analyze` 零 issue;全量 `flutter test` 通过(3,700+ 用例,
  5 跳过均为既有 shimmer/时序 skip),无回归。
