# 2026-09-12

## docs(design): 动画体系调研与选型——全局分级动画 Motion Hierarchy

纯调研落地,不改任何代码。

### 背景

用户反馈:进入/退出登录页有动画,但其他区域几乎无动画 —— tab 切换、设置页点击进入
子页、路由进入/退出都缺过渡;要求按分级(motion hierarchy)调研"官方 vs 社区包"
后选型,让软件更流畅。

### 调研过程(两份并行 subagent 调研 + 本地审计)

1. **本地代码审计**(本仓库):`lib/app/router_helpers.dart` 已有 `fadePage` /
   `tabFadePage` / `slidePage` / `sidePanelPage`;`MotionTokens` / `DurationTokens`
   已建(4 曲线 + 8 时长);`flutter_animate` 4.5.2 已依赖但仅 ~6 处使用;显式
   `AnimationController` 3 处;`Hero` 零使用;无 `AnimatedList`;Forui `FTheme`
   自带 `FThemeMotion` 主题切换动画(200ms);flow_ui 0.1.0 自带流式/呼吸动画。
2. **官方调研**(Flutter 3.38+ 源码与文档、go_router 17.x、M3 motion 规范):
   - `StatefulShellRoute.indexedStack` 官方明确**分支切换无过渡**,须自定义
     `navigatorContainerBuilder`(官方示例 custom_stateful_shell_route.dart),
     M3 称此模式为 Fade through(淡入+轻微缩放,≈300ms)。
   - 子页面路由首选默认 `MaterialPage` + `PageTransitionsTheme`(平台原生、零配置);
     特殊页才用 `CustomTransitionPage`。
   - `PageTransitionsTheme` 默认:Android=PredictiveBack(回退 FadeForwards,450ms)、
     iOS/macOS=Cupertino、Windows/Linux=Zoom(快照,Web 自动禁)、兜底 Zoom。
   - M3 分级:navigation 300–600ms / transitions 200–400ms / micro-interactions
     100–200ms;easing:standard=`(0.2,0,0,1)`、emphasized=`Curves.easeInOutCubicEmphasized`。
   - Hero 跨 StatefulShellRoute 分支不工作(独立 Navigator,#192043)。
   - reduce motion:`MediaQueryData.disableAnimations` 引擎驱动,框架动画自动压缩;
     iOS reduceMotion 暂不互通(#190287 在途)。
3. **社区包调研**(pub.dev/GitHub 实时数据):
   - Flutter 生态正迁向独立 `material_ui` 包(3.47 起),项目**已依赖 material_ui
     1.x**,与 `forui 0.26`、`animations 3.0.0` 同源。
   - `flutter_animate` 4.5.2 维护停滞(2024-11 起),CurvedAnimation 泄漏 bug 未修;
     活跃 fork `flutter_animate_plus` 是升级预案。
   - 推荐:tab 过渡**不引包自写**(navigatorContainerBuilder 20 行);可选引入官方
     `animations 3.0.0`(SharedAxis/FadeThrough;注意 OpenContainer 与 go_router
     不兼容 #121929,勿用于路由);明确不引入 page_transition / motion(GPL-3)/
     rive / lottie / go_router_animated_branch。

### 结论(选型)

三层动画体系,不引大包:

1. **导航过渡**:tab 切换自写 `navigatorContainerBuilder` fade-through(280–300ms
   emphasized);子页面路由先增强现有 `slidePage` 补 `secondaryAnimation` 反向过渡,
   再评估收敛到 `PageTransitionsTheme` 平台默认;设置页桌面 master-detail 加
   `AnimatedSwitcher`。
2. **内容/列表过渡**:flutter_animate 交错进场(限核心列表页)+ `AnimatedSwitcher`
   数据刷新 + Hero 限同分支。
3. **微交互**:优先 Forui 自带(FTappable/FPopover/FTooltip motion +
   `FAccessibilityMotion` 自动降级),flutter_animate 补充自由编排。

无障碍:框架动画自动响应 disableAnimations;自写显式动画统一经 AnimationController
并判断 `MediaQueryData.disableAnimations`;flutter_animate 使用处需补该判断(现状未做)。

### 落地文件

- `docs/doc-map.yaml`:`core-design` 规则 `docs_any_of` 追加 motion-hierarchy 文档。

## feat(shell,settings): Tab 切换 fade-through + 设置页桌面 master-detail 切换动画

动画体系阶段 2(核心痛点)落地。纯前端动画,无后端/契约/l10n 变更。

### Tab 切换(M3 fade-through)

- **根因**:`StatefulShellRoute.indexedStack` 官方明确"分支切换不做过渡"
  (各分支独立 Navigator,`PageTransitionsTheme` 管不到);`tabFadePage` 在分支
  常驻后不再重放,故五 Tab 切换是瞬间跳变。
- **方案**:按官方 custom_stateful_shell_route 示例,`router.dart` 改用一般
  `StatefulShellRoute` + 自定义 `navigatorContainerBuilder`,新增
  `ShellTabBranchContainer`(`lib/features/shell/presentation/tab_branch_container.dart`):
  - 切 Tab 时新分支淡入 + 轻微缩放(0.98→1.0),旧分支淡出(260/200ms,
    `MotionTokens.emphasized`)。
  - **保持 IndexedStack 语义**:所有分支常驻挂载(状态保留);非当前分支
    `Offstage`(对 finder/测试 offstage,与原来一致);隐藏分支
    `TickerMode(enabled: false)` + `IgnorePointer`。
  - 动画时长有界,`pumpAndSettle` 可收敛(全量测试验证)。
- `motion.dart` 新增 M3 对齐 token:`MotionTokens.emphasized`(=
  `Curves.easeInOutCubicEmphasized`)、`emphasizedDecelerate`(=
  `Cubic(0.05, 0.7, 0.1, 1)`)、`DurationTokens.tabFadeThrough`(260ms)/
  `tabFadeThroughOut`(200ms)/`masterDetailSwitch`(220ms)。

### 设置页桌面 master-detail

- `settings/presentation/widgets/master_detail.dart` 右侧 pane 包
  `AnimatedSwitcher`(220ms,`emphasizedDecelerate` 入场,`KeyedSubtree` 按
  `_selectedIndex` 触发),左栏点选切换分组时淡入淡出,替代原 `setState` 直接换 body。

### 测试

- `master_detail_test.dart`:"selecting a different group displays its body"
  从 `pump(150ms)` 改为 `pumpAndSettle()`(动画完成前旧 pane 仍在淡出,
  原断言在动画语义下不成立;真实用户看到的是动画完成后的状态)。
- 验证:`flutter analyze` 零 issue;全量 `flutter test` 通过(3,700+ 用例,
  5 跳过均为既有 shimmer/时序 skip),无回归。

### 落地文件

- `lib/features/shell/presentation/tab_branch_container.dart`(新增)。
- `lib/app/router.dart`(`StatefulShellRoute` + `navigatorContainerBuilder`)。
- `lib/core/design/tokens/motion.dart`(M3 tokens 扩展)。
- `lib/features/settings/presentation/widgets/master_detail.dart`(AnimatedSwitcher)。
- `test/settings/widgets/master_detail_test.dart`(动画语义适配)。
- `docs/explanation/motion-hierarchy.md`(§5 阶段 2 标记完成、§1.2 现状更新)。

## fix(scan): OCR 模型下载 404 修复 + 下载完整性 SHA-256 校验

背景:依赖审计(2026-09-12)发现 OCR 模型下载 URL 失效——上游
`paddle_ocr_native` 仓库**没有** `v0.1.1-models` 这个 GitHub release
(实测 404),但存在 `v0.1.1` git tag 且内含 `assets/models/`。原代码指向
`releases/download/v0.1.1-models`,导致新用户首次进相机下载模型必然失败。

### 分发渠道修复

- `lib/features/scan/domain/services/ocr_model_manager.dart`:
  `_modelBaseUrl` 改为 `https://raw.githubusercontent.com/flespark/paddle_ocr_native/v0.1.1/assets/models`
  (git tag raw 文件;实测 HEAD 200,det 9.9MB / rec 21.2MB)。
- 同时做**架构重构**:抽取 `OcrModelDownloader` 接口(`DioOcrModelDownloader`
  生产实现),下载器与校验器均可注入,`forTesting` 工厂供测试注入。

### 供应链完整性校验(新增)

- 新增 `lib/features/scan/domain/services/ocr_model_hashes.dart`:固定
  det/rec ONNX 与 rec config 三个文件的 SHA-256(与 fork 内
  `doc/model-provenance.md` 一致,已实测上游 v0.1.1 tag 文件逐字节核对)。
- `OcrModelManager.downloadModels()`:每次下载/拷贝后做 SHA-256 校验,
  不匹配即删除文件并抛 `OcrModelIntegrityException`(fail closed,绝不把
  被篡改/替换的模型交给 OCR 引擎)。
- `pubspec.yaml` 新增 `crypto: ^3.0.6` 依赖。

### 残留清理

- 删除本地残留空目录 `pkgs/elk_icon_picker-0.1.3/`(仅剩 .dart_tool,
  未跟踪,2026-08-28 已移除依赖)。
- `pkgs/paddle_ocr_native-0.1.1/pubspec.yaml` 注释同步为「模型不打包、
  宿主下载、SHA-256 在 Luminous 侧校验」。

### 验证

- 新增 `test/scan/ocr_model_manager_test.dart`(3 用例):损坏 det 删除并抛错、
  哈希匹配接受、篡改 config 拒绝。
- `flutter analyze` 相关目录零 issue;`flutter test` 定向用例全通过。


## feat(router): 子页面路由反向让位——slidePage 补 secondaryAnimation

动画体系路由增强落地(原报告阶段 3 第一部分)。

### 变更

- lib/app/router_helpers.dart 的 slidePage 过渡拆两层:
  - 本页作为新页:nimation 驱动从右 15% 滑入 + 淡入(进入)/ 向右滑出 + 淡出(返回),与原行为一致;
  - 本页作为被覆盖的旧页:secondaryAnimation 驱动向左让位约 12%
    (MotionTokens.standard),push 时旧页随新页压入向左退让,pop 时复位,
    形成明确的 push/pop 方向感。

  旧页再让位会与遮罩视觉打架。

  过渡)推迟——当前全站统一 slide 视觉优于桌面 Zoom/移动原生混搭,且涉及
  50+ 路由改动;与 nimations 引入(可选)一起评估。

## feat(design): 引入官方 animations 包,路由过渡与页面状态切换统一为 Material Motion

动画体系品牌统一落地(原报告阶段 5)。引入 flutter.dev 官方的
`animations` 3.0.0(BSD-3,依赖 `material_ui ^1.0.0` —— 与项目主题
`foruiMaterialTheme()` 返回的 material_ui `ThemeData` 同源,类型零摩擦)。

### 变更

- **依赖**:`pubspec.yaml` 新增 `animations: ^3.0.0`。
- **子页面路由**(`lib/app/router_helpers.dart`):`slidePage` 由手写
  slide + `secondaryAnimation` 让位改为官方 `SharedAxisTransition`
  (`transitionType: horizontal`)。push/pop 双向过渡改由包内
  `DualTransitionBuilder` 实现;位移量为固定约 30 逻辑像素(非屏幕比例),
  比原 15% 更克制。时长仍走 `crudPageTransitionIn/Out`(220/150ms)。
- **Tab 根路由**:`tabFadePage` 改为官方 `FadeThroughTransition`
  (260ms / reverse 0),与 `ShellTabBranchContainer` 的分支 fade-through 同模式;
  随之退役 `DurationTokens.tabPageTransitionIn` / `tabPageTransitionOut`
  (仅此一处使用)。
- **全局过渡主题**(`lib/core/theme/family.dart`):`foruiMaterialTheme()`
  新增 `pageTransitionsTheme`,全平台统一
  `SharedAxisPageTransitionsBuilder(horizontal)`,取代平台默认混搭
  (Windows/Linux Zoom、iOS/macOS Cupertino、Android FadeForwards)。
  **说明**:当前所有路由都自带 `pageBuilder`,该配置对现有路由不生效,是
  「未来未指定过渡的路由不再回落到平台默认」的兜底;品牌统一实际由上述两个
  helper 的替换达成。
- **页面状态切换**(`lib/core/widgets/common/feedback/page_state.dart`):
  `PageStateSwitch`(today / medicine / mine / record / review legacy 兼容页共用)
  改用官方 `PageTransitionSwitcher` + `FadeThroughTransition`,骨架 ↔ 内容 ↔
  错误之间由硬替换变为 fade-through。要点:
  - `KeyedSubtree` 按状态变体取 key(loading/error/empty/ready),同变体内数据
    刷新在原地更新、不重播动画;
  - 自定义 `layoutBuilder` 用 `StackFit.passthrough` 保住入参约束 ——
    record 页把它挂在 `SingleChildScrollView` 内,默认 loose Stack 会给子级
    无界约束;
  - 首次构建不播动画(`PageTransitionSwitcher` 首子项 controller 置 1.0),
    页面首帧即时渲染,不影响现有单帧 `pump()` 断言。
  - 新增 `DurationTokens.pageStateSwitch`(240ms)。
