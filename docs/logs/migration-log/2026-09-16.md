## fix(network): 对象存储直传失败按存储侧语义分类

（修复计划 `plans/2026-09-15-review-remediation-plan.md` §3-1。）

### 变更

`putPresignedObject` 此前只把 `DioException` 原样抛出，交给集中错误 mapper 归类。但对象存储回的是
自家 XML/HTML 错误体，不是 RFC 9457 `application/problem+json`——mapper 的 `_fromProblemResponse`
会直接抛 `FormatException`，结果是**每一个**存储侧失败都被降级成 `unknown`，既看不出是链接过期还是
网络断了，也无法据此提示用户重试。

- `core/network/client/object_upload.dart`：PUT 包 try/catch，失败时薄分类——
  403 → business（签名 URL 过期/签名不匹配，这是链接的正常终点，标 `retryable: true` 并带上状态码，
  可提示「链接已过期请重试」）；其它有响应 → server；无响应 → network。traceId 一路带出，
  与 Lucent 请求的排障口径一致。
- `core/network/contract/error_mapper.dart`：`_errorCodeFromDioType` 提升为公开的
  `errorCodeFromDioType`，让存储侧分类复用同一套连通性错误码词汇，而不是另造一份。
- `core/network/README.md`：补陷阱说明——存储侧错误不经集中 mapper，PUT 自带分类。
- `test/core/network/object_upload_test.dart`：补四条用例——403 为可重试的 business 类并带状态码、
  其它 HTTP 错误为 server 类、无响应的传输错误为 network 类且错误码正确、traceId 透传。

### 验证

- `flutter analyze` 无问题；`flutter test test/core/network test/record test/scan` 全绿
  （另两条直传链路：头像与记录图片上传共用本函数，一并覆盖）。

## fix(health_context): 快照缓存反序列化容忍错类型字段

（修复计划 `plans/2026-09-15-review-remediation-plan.md` §3-2。）

### 变更

快照缓存的反序列化对多个字段用硬 cast（`as String?`、`as double?`、`List.cast<String>()`）。
缓存行由旧版本写入、或只是单纯损坏时，只要有一个字段类型对不上，整份快照就抛
`TypeError`——而它只是缓存，网络上的正确数据就在旁边，却会连带整个 `fetchHealthContext`
失败。`List.cast<String>()` 还更隐蔽：它是惰性转换，异常抛在元素首次访问处，离越界的那条
数据很远。

- `data/utils/health_context_snapshot_codec.dart`：标量读取改走 `_asString` / `_asInt` /
  `_asDouble`，类型不符即丢该字段（`_asDouble` 接受 `num`，因为 JSON 不区分 `170` 与
  `170.0`）；列表读取改走 `_asStringList`，逐元素判定、非字符串丢弃、非字符串但可
  字符串化的保留。文档注释写明这是有意的降级：丢字段后调用方会重新拉取并回写缓存行。
- 集合元素的 `as Map<String, dynamic>` 保持不变——那是快照自身结构，不是缓存陈旧问题。

### 验证

- 新增 `test/health_context/health_context_snapshot_codec_test.dart`：整份快照 round-trip
  保真，加上错类型字符串丢弃、整数接受为 double、错类型数值丢弃、列表元素混合类型、
  字段缺失、summary 字段错类型共六条容错用例。
- 反向验证：临时把 `activityLevel` / `heightCm` 还原成硬 cast，新用例如期以
  `type 'int' is not a subtype of type 'String?'` 等失败；恢复后全绿。
- `flutter analyze` 无问题；`flutter test test/health_context test/core/database test/mine`
  全绿。
