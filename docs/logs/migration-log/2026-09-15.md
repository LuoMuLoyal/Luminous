## feat(record): 症状目录扩至九项并消费后端目录,「其它」支持就地输入

（症状链路优化 Phase 3 客户端侧；计划文档 `plans/2026-09-14-symptom-chain-optimization.md`，执行完毕后删除。）

### 变更

- `domain/constants/symptom_catalog.dart`：`SymptomCode` 扩到九项（+ nausea / cough / fatigue /
  insomnia / other），新增 `SymptomCatalogEntry`（码 + 展示文案）。
- `domain/constants/fast_entry_choices.dart`：症状选项改由 `fallbackSymptomCatalog(l10n)` 生成（本地兜底清单，
  与 Lucent `SYMPTOM_CATALOG_CODES` 同码同序）；新增 `symptomCodeLabel()` 与
  `resolveSymptomChoices(catalog:)`——**顺序与成员资格以后端目录为准，文案优先本地、未知码用后端 label**。
- 新增 `data/providers/symptom_catalog.dart`：`GET daily-records/symptom-catalog`（生成的
  `getSymptomCatalog()`），失败/未登录返回空表。
- `presentation/services/quick_entry_executor.dart`：症状分支改为同步读已缓存的目录（`loadSymptomCatalog()`）再
  按启用码过滤——**录入不等网络**，首屏立刻用本地目录打开 sheet，后端目录在后台刷新、下次打开生效；「其它」的
  `customLabel` 作记录标题并写进 payload。
- `presentation/widgets/dialogs/symptom_quick_entry_sheet.dart`：选中「其它」不立即落库，在网格下方
  **就地展开输入框**（自动聚焦，空值保存置灰，返回可退出）；多选态下「其它」不可选。
- l10n 新增五个症状文案 + `recordSymptomCustomLabel`；生成客户端随之更新
  （`getSymptomCatalog` → `SymptomCatalogResponse`）。

### 验证

- `flutter analyze` 无问题；`flutter test test/record` 530 例通过。
- 新增/更新用例：目录码表扩到九项、`fromWire` 未知码仍返回 null；sheet 的「其它」就地输入（空值禁用保存 →
  输入后返回 `customLabel`）与多选态禁用；page_test 三条症状用例在新 sheet 上验证 payload
  （`{symptom, severity}` / `{symptom, customLabel, severity}`）。

### 记录一处设计取舍

首版让录入 `await` 目录请求，结果测试里 sheet 永不出现——**快速记录不能等网络**。改为同步读缓存 + 后台刷新：
首屏永远来自本地兜底清单（离线可用、无 loading 态），后端目录的增删与顺序在下一次打开时生效。
