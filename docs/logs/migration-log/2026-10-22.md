# 2026-10-22

## fix(ci): 解析 path 依赖子包的依赖，修复 analyze 失败

- `flutter analyze` 会分析 `pkgs/` 下的源码，但根 `pub get` 不会为 path 依赖的
  子 package 各自解析依赖。`pkgs/luminous_native_bridge/pigeon/steps.dart` 引用了
  只在该包 `dev_dependencies` 里的 `pigeon`，干净 clone 上以
  `Target of URI doesn't exist: 'package:pigeon/pigeon.dart'` 失败；本地能过是因为
  之前手动在子包跑过 `pub get`，`.dart_tool/package_config.json` 里已有 pigeon。
- CI 在 analyze 前新增「Resolve sub-package dependencies」，对
  `pkgs/luminous_native_bridge` 与 `pkgs/paddle_ocr_native-0.1.1` 各自跑
  `flutter pub get`；`generated/lucent_api` 已有独立步骤，不重复。
- 顺带修复 Scorecard：`push.branches` 原本含 `develop`，而 `scorecard-action`
  只接受默认分支，非默认分支上以 `only default branch is supported` 失败。
  收窄为 `branches: [main]`。
- 验证：`flutter analyze` 无 issue；两个子包 `flutter pub get` 均成功。
