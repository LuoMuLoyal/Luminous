# 2026-10-27

## refactor(icon): iconMind 退场，图标统一 Lucide 并全局去重

- **触发**：用户反馈 iconMind 图标「大小不一致、每个图标都有衬底」，要求弃用 iconMind、
  统一 Lucide，并强调「严禁同一个页面出现两个含义不同但图标相同的地方」，不允许复用。
- **实测根因（墨迹包围盒，非 viewBox）**：iconMind 111 个 SVG 的图形实际占用范围
  8.46–20.00（24 框内），**极差 2.36 倍**；对照 Lucide 实测 15 个在用字形为 13.97–22.03，
  极差 1.58 倍。直接后果是 `capabilities_panel.dart` 四处都写 `size: 14`，实际画出
  9.3–11.7px，**同一尺寸参数差 26%**——这是「大小不一致」的真实来源。
- `agent.svg` 另有定位缺陷：路径只覆盖 y=2.94–12.00，底部 12 单位全空、图形顶在框上半部，
  而它正是欢迎区 `size: 40` 的 hero 图标（实际只画出 15.1px 墨迹）。换回 Lucide `bot`
  后这一处恢复居中正常尺寸。
- **「衬底」与 iconMind 无关**：来自 `SoftIcon`（默认 44px 圆角块装 24px 字形，填充率仅 55%）
  与 23 处把 `FAvatar` 当图标托盘。**本次未动**，留待计划 P3。
- **迁移**：iconMind 声明的 34 个语义位中只有 5 个真正在用，涉及 6 个调用点、2 个文件。
  其中 `aiEntry`/`aiGenerated` 与 `SemanticIcons` **同名冲突**（两边各有一份实现），
  按「删 SVG 侧、留 Lucide 侧」处理；`aiMemory`/`aiKnowledge`/`aiToolCalling` 新增为
  `memoryStick`/`database`/`wrench`（已核实三者此前未被占用）。其余 29 个是死代码，随文件删除。
- **删除**：`assets/icon/iconmind/`（112 文件 / 34.1 KB，含 LICENSE）、
  `lib/core/design/tokens/semantic_icon_svg.dart`、`pubspec.yaml` 的 asset 声明、
  `design.dart` 的 barrel 导出。`flutter_svg` 依赖**保留**（`oauth_panels.dart` 仍在用）。
- **去重（本次重点）**：原 13 组「不同语义名 → 同一图标」，按两条规则清理：
  1. **全局唯一**：`SemanticIcons` 每个语义名必须映射到不同字形。
     删除 9 个零引用冗余名（`doseSkipped`、`dosePending`、`reportReady`、
     `reportInsufficient`、`safetyPregnancy`、`safetyCaffeine`、`profileAllergy`、
     `profileMedicine`、`statusInfoCircle`），并修正 1 处有引用的
     （`more_actions.dart` 的 `reportExport` → `actionExport`）。
  2. **不许复用**：原本被判定为「跨语境可复用」的组全部拆开，换独立字形——
     `tabMedicine`(`pillBottle`→`tablets`)、`safetyTiming`(`calendarClock`→`clockAlert`)、
     `reportInsight`(`lightbulb`→`telescope`)、`safetyLongTerm`(`hourglass`→`calendarRange`)、
     `safetyDuplicate`(`copySimple`→`layers`)、`doseTaken`(`checkCircle`→`circleCheckBig`)、
     `notificationDelivered`(`bellRinging`→`bellCheck`)。
     其中后四项是 **Lucide/Phosphor 跨族同形**（如 `circleCheck` vs `checkCircle`），
     按概念归一化后同样算重复，一并拆开。
- **结果**：115 个语义名 → **115 个互不相同的字形**，跨族同形 0 组；
  同文件内不再存在「两个不同语义名指向同一图标」。已用脚本对 `lib/**` 全量校验
  （全局唯一性 + 逐文件碰撞检测），并新增计划文档记录该检查方法。
- 验证：`flutter analyze` 无问题；`flutter test` 全绿；全仓 `iconmind` / `SemanticIconSvg`
  零残留；`docs/reference/generated/design-tokens.md` 已重新生成。
- 未做（见 `plans/2026-10-27-icon-family-consolidation-lucide.md`）：尺寸刻度收敛
  （`Spacing` 当图标尺寸的 63 处）、衬底清理、以及防复发的自定义 lint 规则
  （用户明确指示 lint 规则先不做）。

## 图标去重（Scope B）：页面内按区块拆分

上一轮只做到「不同语义名 → 不同字形」的**全局唯一**。用户进一步要求：**同一个页面内，
除返回 / 提示 / 错误这类确实需要复用的，其余一律不得出现同一字形**，包括跨区块、
跨组件的重复；只有同一个列表行内的同类条目允许复用。

- **判定规则**（可机检）：以一个页面路由为根，沿 `package:luminous/...` import 求
  可达文件集合（排除 `app/router.dart`，否则会因它 import 全部 feature 路由而把整仓
  算成一页）；只统计 `features/**/presentation/**` 下的引用点——只有这些会真正渲染。
  同一 token 出现在同一页面的 **2 个以上 presentation 文件**即判定为复用。
  白名单仅 `actionNext/Prev/Expand/Collapse/Close`（返回与导航）、
  `statusInfo/statusWarning/statusError/aiTip`（提示与错误）。
- **修法**：拆分出来的新 token 字形**只从该 token 的语义族里取**（同一图标的近义变体），
  不随机挑字形。例：`statusDone` → `checkCheck`/`circleCheck`/`squareCheck`/
  `circleCheckBig`/`fileCheck`；`safetyCaution` → `shieldQuestion`/`shieldEllipsis`/
  `triangleAlert`；`statusPending` → `clock1`/`clock2`/`clock5`/`taskTimer`；
  `actionSettings` → `settings2`/`sliders`/`columnsSettings`。
  新 token 命名 `<原token><区块文件 PascalCase>`，并在注册表内注明来源文件。
- **顺带修掉的真错配**：`safetyCaution` 被当成「已确认安全」结论、`doseSlot` 被当成
  「上次检查时间」、`reportAdherence` 被当成「提醒已送达」、`tabRecord`/`tabReview`
  被当成内容图标与错误态图标、记录类型 `symptom` 用了 `medicineKit`、`note` 用了
  tab 图标——这些都改回了语义正确的 token（`safetyVerified`、`doseCheckedAt`、
  `notificationSent`、`statusError`、`recordSymptom`、`recordNote`）。
- **语义合并**：`recordMoon` 与 `recordSleep` 表示同一个「睡眠」语义却用了两个字形，
  统一为 `recordSleep`；原 `recordMoon` 的深色主题用法改名为 `actionThemeDark`。
- **结果**：语义 token 从 115 → **230**，字形 230 个互不相同（全局唯一仍成立）；
  **同一页面内跨 presentation 文件的同名 token 重复 = 0**。
- 验证：`flutter analyze` 无问题；`flutter test` 全绿（断言同步更新）；
  校验脚本覆盖三项——全局字形唯一、页面内不同 token 同字形为 0、页面内 presentation
  引用重复为 0。
